# 协议与产物契约

**本文件是指标与数据口径的唯一规范。实现、配置、表格和稿件不得各自解释同一个字段。**

版本：`caap-protocol-v1-draft`。D1 确认后冻结为带 SHA-256 指纹的正式版本。以下路径均相对工作区；涉及 Python 包时工作目录为 `CAAP_code/`。

## 1. 数据角色与可见性

### 1.1 输入角色

| **角色** | **用途** | **禁止事项** |
| --- | --- | --- |
| `recognizer_train` | 识别器历史训练样本，记录是否可追溯 | 不伪造训练来源 |
| `patch_train` | 补丁、ASIT、辅助特征预训练、训练目标原型 | 不包含最终 probe 或校准 probe |
| `attack_val` | 选择 epoch、模块、形状和有限超参 | 不替代阈值校准或最终测试 |
| `calibration` | 只以干净分数选择验证阈值 | 不用于攻击选择；不使用攻击图调阈值 |
| `gallery` | 固定干净注册模板 | 不含自身 probe；不偷偷按测试表现选模板 |
| `test_probe` | 冻结后评估所有预注册条件 | 不调参、不重新选目标/epoch/种子 |

`patch_train`、`attack_val`、`calibration`、`test_probe` 图像严格不交。`gallery` 可按公开协议使用 `recognizer_train` 中的图像，允许与 `patch_train` 重合但必须记录，并和所有验证/校准/测试 probe 不交。

固定历史识别器可能见过 session1 中后续划作 `attack_val/calibration` 的图像。必须披露这种模型训练可见性；它不自动是攻击选模泄漏，但不能称为所有学习组件均未见过的独立身份泛化。

新训练 MS-DIFE 只读 `patch_train`，不得先用全部 train 预训练后再声称 attack_val 对所有组件独立。

### 1.2 默认分割政策

优先还原真实官方/作者 manifest。Tongji 若确认 session1/session2，可在 session1 内分配补丁训练、验证与校准，session2 保持最终 probe；具体比例在 D1 前按每掌数量冻结。

候选示例为每掌 session1 的 10 张按固定顺序/种子分成 `6/2/2`，图库从训练角色选固定样本。**这只是候选，资产不符时不能强套，也不能声称当前 `.pth` 已按此划分。**

已有 `.pth` 只有 train/test 时，保存导入的 split 来源，生成全局图像 ID、内容哈希、分层留出列表。缺少 session 元数据就标记 `session=unknown`，不猜它是跨 session。

必须阻断：`val_ratio<=0`、角色交集不合法、重复图跨分割、目标类无样本、标签越界、同类采样候选不足。测试身份不在闭集头时，不能继续套用闭集分类指标。

历史测试已参与选模/论文设计时须记录 `historical_test_exposure=true`；重跑可以减少新的泄漏，但不能宣称测试从未被使用。若有额外未触碰确认集，另行预注册，不能事后声称独立。

### 1.3 样本 manifest

每条记录至少包含：

| **字段** | **类型** | **含义** | **约束** |
| --- | --- | --- | --- |
| `sample_id`、`sha256` | string | 全局稳定 ID 与原始样本指纹 | 跨 split 唯一，不能仅用局部数组下标 |
| `dataset_id`、`source_ref` | string | 数据来源及授权登记引用 | 不公开私密路径或真实姓名 |
| `palm_id`、`class_id` | string、int | 掌级凭据与连续分类标签 | 映射落盘，不假设从 0 开始的原始标签 |
| `subject_id`、`hand_side` | string/null | 去标识的人级 ID、左右手 | 未知写 null，不能用整数除法猜 |
| `session_id`、`role` | string/null、string | 采集批次与用途 | role 来自已知枚举 |
| `shape`、`pixel_space` | array、string | 通道尺寸、数值定义 | 原始图为有限值，范围可验证 |

指纹可以在安全环境中内部保存；向论文公开时按许可输出匿名统计，不公开生物模板、面向个人的可识别映射或不必要原图。

## 2. 模型与像素空间

所有合成、打印导出和图像指标在原始 \([0,1]\) 灰度 ROI 空间完成。模型归一化只在识别器适配边界执行一次，归一化策略必须和权重训练一致。

`aug_org` 若使用逐 ROI 标准化，必须保留原始像素，禁止把标准化后图像直接当原图贴补丁/截断；无法安全支持时显式拒绝，不静默改用 `aug_0.5`。

每个模型登记结构名、实际类、类别数、输入尺寸、训练归一化、权重 SHA-256、代码指纹和训练来源。当前通用 CNN 是本地变体，不能仅凭 `vgg16` 名称写成 torchvision 标准模型。

正式实验要求真实已验证权重，加载时严格检查缺失/多余 key、分类头和维度。使用 `weights_only` 或安全等价加载方式；不自动执行不可信 pickle。合成随机权重只能在显式 `synthetic/test` 模式使用。

洁净准确率必须与同权重、同 manifest 的参考评估一致。没有可信参考时可预先设项目自己的有效性阈值，但须 D1 冻结，不用任意阈值包装成领域标准。

## 3. 补丁能力与预算

### 3.1 评估模式

- `deploy-fixed`：仅加载纹理、掩码、固定 placement；不调用 ASIT、输入梯度定位、标签条件生成或逐图光度烘焙。真实标签只供最终评分。
- `input-conditioned`：允许当前 ROI 驱动 ASIT；记录所有依赖。兼容旧接口 `oracle`，输出必须写明语义，不称上界。
- `physical`：读真实拍摄，经固定预处理和识别器评分；不数字移动/重绘已拍补丁。

中心位置是主协议候选，由配置冻结。位置试验有单独配置，不能只因设置了 `mode=deploy` 就假定 `canvas_loc=center`。

主模式不读取测试图选择打印模板；训练集常数光度烘焙若开展，是预注册的独立 artifact variant，并有独立哈希和验证选模。

每个 artifact 声明 `supported_modes`。没有 ASIT 时，队列将 G/P/GP 诊断登记为 `NOT_APPLICABLE`，不伪造恒等变换结果、不重试。用户直接请求不支持模式时接口返回 `UNSUPPORTED_MODE`。H1 使用明确含 ASIT 的 `ablation_reference`，主方法不含 ASIT 也不丢掉这项参照。

含 ASIT 的诊断分别锁定几何/光度开关；`scale_policy=fixed_one/predicted` 进入评估键。D 不调用 ASIT；G/P/GP 只激活相应输出，不把关闭分支悄悄恢复。

### 3.2 三层面积

共同主预算候选 `B=784`，图像 `128×128`，完整二值形状满足 \(0.98B\le A_0\le B\)。禁止为了凑面积随意删方形边角却仍称完整方形。

若某种形状不存在满足约束的离散实例，返回 `BUDGET_INFEASIBLE`，在 D1 前更改共同预算或明确放宽公差；不能在代码中暗中超预算。

同时记录：`binary_area`、`bbox_w/h`、周长计算方法、alpha 总和、`alpha>1e-6` 支撑面积、实际 `abs(adv-clean)>1e-6` 支撑面积、可见/裁剪比例。抗锯齿和阈值均入配置。

主形状比较关闭边缘平滑、固定尺度；软边另行消融。传统十字 `L40,w11,A759` 作为 `legacy759` 独立对照，不和新预算混表。

训练或诊断变换后的面积必须测量。独立的整图采集变换可能改变 ROI 中可见面积，这不等于偷偷增大打印物；各方法共享采集条件并报告变化，禁止事后缩回面积导致虚构采集过程。

### 3.3 几何与随机流

公共渲染接口以**正向可解释几何**定义：`tx>0` 输出向右、`ty>0` 向下、`scale>1` 图案变大，旋转方向固定并测试；内部显式换算为 `affine_grid` 的逆采样矩阵。

固定 `align_corners`、插值和边界策略，禁止同一位移在画布与仿射中重复应用。

训练采样、数据划分、patch 初始化、eval 变换、bootstrap 分别使用独立随机流；评估消耗随机数不得改变下一轮训练轨迹。

正式种子候选 `{0,1,42}`。原始配置 seed=42 的历史结果不替代新协议任一 seed。

## 4. 分类与退化指标

令 \(\hat y_i^c\) 为洁净预测，\(\hat y_i^a\) 为攻击预测，真实标签为 \(y_i\)。

未定向有效集合 \(\mathcal E=\{i:\hat y_i^c=y_i\}\)：

\[
ASR_u=\frac{\sum_{i\in\mathcal E}\mathbf 1[\hat y_i^a\ne y_i]}{|\mathcal E|}.
\]

定向目标 \(t\) 必须真实存在，\(\mathcal E_t=\{i:\hat y_i^c=y_i,\ y_i\ne t\}\)：

\[
ASR_t=\frac{\sum_{i\in\mathcal E_t}\mathbf 1[\hat y_i^a=t]}{|\mathcal E_t|}.
\]

每条指标保存 `n_total/clean_correct/k/n/rate`。`n=0` 返回 `rate=null,status=INVALID_DENOMINATOR`，不是 0%。内部 rate 用 `[0,1]`，表格展示百分数；差值单位明确为百分点。

对退化 \(T_\xi\)，洁净与攻击图使用同一个随机实现 \(\xi\)。主要条件 ASR 用 `T(clean)` 正确的集合；另报固定标称洁净集合上的结果、退化洁净准确率和攻击后准确率，避免样本组成变化被隐藏。

`K_eval` 次独立渲染的单次成功率估计，与预测多数投票、允许 k 次重试是三种不同指标。每个 probe 固定相同 draw 数 J，令 `e_ij` 表示第 j 次退化 clean 是否满足条件，`s_ij` 表示该 draw 的攻击成功事件。**主退化指标为有效 draw 池化的条件率**：

\[
ASR_{draw}=\frac{\sum_i\sum_j e_{ij}s_{ij}}{\sum_i\sum_j e_{ij}}.
\]

其 `k/n` 是成功有效 draw 数/全部有效 draw 数；另存 `n_probes_total/n_probes_with_eligible_draw/n_draws_total`。probe 全部 draw 无效时保留记录，主分母不计入；全部 probe 无效时 invalid/null。

可选 `probe_macro_conditional` 先逐 probe 计算条件率，再对至少一个有效 draw 的 probe 等权平均，必须另命名并保存每 probe 的 k/n，不能用汇总整数 k/n 冒充该均值。例：A 有效 4 次、成功 4 次，B 有效 1 次、成功 0 次，主 ASR=4/5=80%，宏平均=50%。

随机评估的 bootstrap 按身份整簇保留其全部 probe/draw，再重算上述比率，不把各 draw 当独立人。多数投票如有单独命名。固定标称集合的指标使用该集合全部 J 次 draw，不按每 draw clean 再过滤。

同 checkpoint 的模式差在共同 ID/draw/同一 eligibility 上配对计算。跨模型比较各自条件分母时必须展示分母；需要共同集合时显式输出交集，不替换原结果。

### 4.1 视觉指标合同

S05 计算 clean 与标称合成图在原始灰度空间的视觉指标，`data_range=1`，在整图外部退化之前执行，避免把相机变化计为补丁外观。另测退化外观时使用独立命名条件。

全图 MAE/MSE/PSNR 与局部区域读数均逐图保存；局部区域 R 固定为该 artifact 的二值掩码外接框，向外扩 3 px 并裁到图内，不根据误差大小调整。跨形状比较同时报告 R 的尺寸，不能假装局部区域一样大。PSNR=`10*log10(1/MSE)`；MSE=0 时 `psnr=null,psnr_status=PERFECT_MATCH`，汇总报告完美匹配数量和有限值分布，不把无穷写入 JSON 或替换任意大数。

SSIM 固定窗口 `11×11`、Gaussian sigma=1.5、K1=.01、K2=.03，使用 population covariance，边界 reflection；局部 SSIM 为全图 SSIM map 在 R 内的均值，不对小 crop 悄悄更换窗口。实现与独立参考小图对照，声明库版本和边界。

纹理 TV 仅对掩码内相邻的水平/垂直有效像素对取绝对差均值；无有效邻接对时 null/invalid，不计掩码外填充值。此为报告指标，训练损失若采用其他 TV 定义必须分别命名。逐图值按 probe 等权汇总，不把重复 draw 混为新图。

## 5. 验证协议

### 5.1 注册、校准和目标

使用模型稳定 embedding 接口，如 `getFeatureCode`。没有接口则 `UNSUPPORTED_MODEL`；不临时把 logits 当认证特征。

主凭据单位为同一掌。不同掌是不同模板；已知为同一人的另一掌单列标记，不默认合为 genuine。完全人级融合需要另定义注册规则，不属于本轮默认协议。

图库模板由干净训练角色的固定图像计算，平均方式和 L2 归一化冻结。图库图不进入校准和测试 probe。

校准集生成 genuine 和预设 impostor 对：记录对数、身份数、采样 seed、是否排除同人另一掌。重复配对必须去重，不能用测试图挑“最容易接受”的目标。

### 5.2 阈值与指标

相似度为余弦分数，统一规定 `score >= tau` 为接受。

- `FMR(tau)`：预设非匹配对被接受比例。
- `FNMR(tau)`：genuine 对被拒绝比例。
- `TAR=1-FNMR`；接口层 FAR/FRR 若保留，明确这里只测 matcher，不是含活体的全系统。
- `EER`：干净测试分数的描述性曲线汇总，可计算但不用于部署选阈值。
- `tau_eer_cal`：仅从干净校准集选择的 EER 近似阈值。
- `tau_fmr_cal(alpha)`：仅校准集选择满足经验 FMR 上限的最低阈值，tie 和端点行为固定；候选 `alpha=1e-2,1e-3`。

阈值搜索包含全接受/全拒绝端点；分数全等、无 genuine/impostor、零范数 embedding、尾部样本不足都显式处理。仅有全拒绝解时标记 `DEGENERATE_OPERATING_POINT`，不把它写成有效认证工作点。JSON 不写 NaN/Infinity。

最终测试同时报实际 clean FMR/FNMR 与 attack FMR/FNMR；校准目标 1e-3 不保证测试也为 1e-3。

未定向报告本人拒绝风险与相对 clean 增量；定向报告攻击者对固定目标模板的接受率，并分别给所有合法目标对上的比例及“clean 原先拒绝”条件比例。二者分母不能混用。

原 logit 攻击不自动是最强验证攻击。若结果显示验证风险低，只能限定当前攻击；新验证损失属于额外协议，不临时补进原矩阵。

### 5.3 不确定性

数字主结果逐 seed 报 `k/n`，跨 seed 报均值、标准差和全部点；三个 seed 不支持强分布推断，不堆叠三个 seed 的重复 probe 当作三倍样本。

固定 artifact 条件下，按 `subject_id` 整簇重采样，未知 subject 时按 palm 并声明可能低估双掌相关性。所有配对条件共享重采样索引。默认 bootstrap 2000 次、固定 seed；样本很少或全 0/1 导致区间退化时显式警告。

验证 pair 保存 probe 端与 template 端的聚类身份。默认对两端身份的并集做同一次有放回抽样，得到 multiplicity `m_u`：不同身份的 pair `(u,v)` 权重为 `m_u*m_v`，同一身份两端权重为 `m_u`，clean/adv 共用权重；以加权成功数/有效数计算每次复本。已知同人双掌使用同一个 subject cluster，但仍遵守掌级 genuine 规则；未知 subject 则退到 palm 并警告。禁止只重采样 probe 端却声称覆盖了模板端相关性。

该区间条件于**已训练 artifact、已登记图库采集及固定校准阈值**，不包含训练、重新注册或重新校准的不确定性。固定单一目标接受实验默认固定目标身份，只重采样攻击者身份，不能把固定目标说成人群随机目标泛化。复本有效分母为零时报告无效复本比例；不足以形成区间则 null，不能静默补 0。

同时给 seed 离散度，不声称单一 bootstrap 同时覆盖训练随机性和全部人群不确定性。

Wilson 可作为 `k/n` 的参考描述，不能代替重复拍摄/共享身份的聚类推断。低 FMR 同时报不同身份数、唯一 pair 数和采样规则；不利用海量相关 pair 声称极低尾部率已获精确验证。

## 6. 物理逐次记录

最低字段：`capture_id,subject_id,palm_id,attempt_index,session_id,condition_id,device_id,distance,pose,illumination,patch_id,print_variant,attack_mode,target_id,model_id,preprocess_id,clean_pair_id,prediction,score,success,valid_capture,failure_reason`。

唯一键包含 capture、模型与评价模式，禁止重复计数。成功必须由模型输出和协议导出，不能人工编辑成期望值。距离/姿态单位写入表头或元数据；未知条件写 unknown。

原稿黑白和 RGB 物体分别绑定 `patch_id`；多个物体合并时标记 artifact pool，不能声称单一物体性能。攻击模式、目标、模型和条件不得串组。

报告：单次 micro、每人平均 macro、每人 `k/n`、受试者聚类区间、实际按时间顺序前 k 次的 `ASR@k`。默认 `k=1,5,20`；缺顺序或不足 k 次则 null 并报告合格人数及缺失原因，不自动删除失败尝试。

旧工具的 \(1-\binom{n-s}{k}/\binom nk\) 是从已观察 n 次中随机无放回抽 k 次的估计，只能另命名 `random_subset_success_at_k`；不是实际前 k 次 ASR。不得用独立假设公式生成观测结果。

预处理失败/捕获失败保留在流程台账，条件识别率与全尝试流程率分开；不静默扔掉失败照片。缺洁净配对时只能报告观察到的攻击条件表现，不能声称净效应全部由补丁造成。

## 7. 任务身份、产物与状态

**训练和派生评估都是任务图中的节点，但不共享同一套必需文件。** 例如校准没有补丁 checkpoint，常数纹理没有训练 seed；不能为通过收集器而伪造这些字段。

### 7.1 任务清单与科学键

`experiment_manifest.json` 包含版本、冻结的完整 `protocol_hash`、批准记录、节点列表和预期表格单元。每个节点至少声明：

| **字段** | **含义与约束** |
| --- | --- |
| `task_id/task_type` | 稳定逻辑 ID 与下节枚举类型；显示名不是去重依据 |
| `input_refs` | 按角色命名的父 `task_id/output_name` 或外部资产指纹；必须无环、类型相容 |
| `config_ref/protocol_sections` | 已解析配置与本节点真正依赖的协议小节；不可藏默认值 |
| `seed_policy` | 分别记录 train/generator/draw/bootstrap seed；不适用为 null |
| `applicability` | 所需能力、适用条件、缺资产和不适用原因；不能按 ASR 决定 |
| `expected_outputs` | 类型、schema、文件名和必需性；与 §7.2 对应 |
| `resource_limits` | 设备、时长、更新数、存储及重试余额 |
| `comparison_refs` | 基准节点、唯一变化字段、预期表格单元及跨角色复用关系 |

科学键 `scientific_key` 用于判断“是否在做同一个计算”。输入是规范化 JSON：`schema_version + task_type + 相关协议子集指纹 + 相关实现/环境指纹 + 解析后的科学参数 + 按角色排列的输入内容指纹 + 适用随机种子`，再取 SHA-256。对象键排序、数值与 null 规范固定，禁止 NaN；有顺序含义的列表不排序。

完整 `protocol_hash` 和工作树指纹总是保存在 provenance 中；键使用显式依赖子集，以免纯阈值修正强迫重新训练补丁。未知实现影响默认不复用；只有证明不影响该节点的纯文案/无关代码变更，才能登记兼容理由。不得手工忽略影响科学结果的字段。

路径、时间戳、日志级别、worker/机器昵称不进入科学键；真实资产内容、精度、训练 microbatch/累积、变换、优化和选择规则必须进入。eval batch 等执行参数仍保存；只有通过逐样本等价测试的无语义变化才允许同键重试。

父任务尚未完成时，保留稳定的逻辑引用，科学键标记 pending；父输出 hash 校验通过后才解析键并领取任务。重试前重新校验，不能把旧父输出自动替换为新输出而沿用旧键。

| **task_type** | **除公共字段外必须进入科学键的输入** |
| --- | --- |
| `train_patch` | patch_train/attack_val、源识别器、辅助权重或随机 seed、mask/placement、损失/优化/EOT/选模配置、train seed |
| `train_feature` | 预训练及内部验证 manifest、结构/头、预处理、优化/选模、train seed；不引用最终 test |
| `generate_control` | mask/placement、纹理生成规则/参数、generator seed；如灰度来自训练统计，加入统计产物 hash |
| `calibrate` | 目标模型/预处理、gallery 模板及生成规则、calibration、pair 规则/seed、阈值算法/工作点；**不依赖 patch** |
| `eval_classification` | patch/control artifact、目标模型、probe/标签映射、渲染模式/几何/光度/尺度、condition/draw 数及 seed、eligibility 和指标规则 |
| `eval_verification` | patch/control、目标模型、gallery、probe/pair 规则、渲染条件、calibration/threshold hash、指标和 bootstrap 配置 |
| `analyze_structure` | 原图/mask、相关预测、冻结结构提取/统计配置、分组及 bootstrap seed |
| `analyze_visual` | 原图、合成图或可复现渲染输入、mask、固定视觉指标配置；不依赖认证阈值 |
| `physical_report` | 实拍 manifest、真实逐次预测、打印物/模型/预处理、分组/重试/无效采集/统计规则 |
| `collect_report` | 当前冻结矩阵及 expected_cells、所需上游结果 hash、表格/主张映射和格式配置 |

同一补丁在不同目标模型、条件、D/G/P/GP 或阈值上评估有不同键。相同 calibration 输入的不同方法共用校准节点；不同阈值修订只影响声明依赖该阈值的验证与报表，不影响分类评估或训练。

矩阵中的多行可以引用同一科学键，如主方法恰好等于某消融配置；记录 `reuses_scientific_key`，只计算一次。把同一 run 的重试或多个显示别名计为新的 seed/样本，属于重复计数。

### 7.2 按任务类型定义产物

每次执行尝试有唯一 `run_id`，使用 `caap_revision/runs/<run_id>/` 原子创建，不覆盖旧目录。任务科学键相同不表示重试目录相同。

所有任务共同必需：`resolved_config.json`、`provenance.json`、`status.json`、追加写的 `events.jsonl`、`artifact_manifest.json`。它们分别记录解析配置、全局/局部协议及代码/环境/输入指纹、状态/退出码/资源、事件、输出类型/schema/指纹和依赖。

| **task_type** | **额外必需产物** | **不要求或不适用项** |
| --- | --- | --- |
| `train_patch/train_feature` | 完整 `checkpoints/latest.pth,best.pth`、训练/验证曲线、实际预算、选模记录 | 最终测试预测由独立评估节点生成 |
| `generate_control` | 纹理、mask、placement 和生成参数；`origin=generated_control` | 无 optimizer/checkpoint；`train_seed=null` |
| `calibrate` | `calibration_scores.jsonl`、图库引用、`thresholds.json`、阈值 hash | 无 patch/训练状态，不读取 test probe |
| `eval_classification` | `predictions.jsonl`、`metrics.json`，逐 sample/condition/draw 的 clean/adv、k/n、面积 | 不构造 optimizer、不重新选 patch |
| `eval_verification` | `pair_scores.jsonl`、两端身份/eligibility、固定阈值结果、相关联合计数 | 不根据 test 分数调整阈值 |
| `analyze_structure` | `structure_records.jsonl`、分析配置、分组结果及设计不足状态 | 不重新优化 patch，不补造标签 |
| `analyze_visual` | `visual_records.jsonl`、R 区域、逐图指标、汇总与边界状态 | 不伪造有限 PSNR，纯 TV 无 k/n |
| `physical_report` | `capture_audit.json`、逐次结果引用、分组/重试/聚类指标 | 无训练 checkpoint；不制造缺失拍摄 |
| `collect_report` | CSV/JSON 表、`coverage.json`、主张及 reviewer 映射 | 不训练，不给缺失结果填 0 |

阈值端点以 `decision_rule=always_accept/always_reject`、`tau=null` 表示，普通阈值写 `score_ge,tau=<finite>`，避免 Infinity JSON。所有指标保留单位、分母类型、区间方法和 eligibility 指纹；无分母的元数据/连续指标不强行套 k/n。

`evidence_type` 以被评估的数据来源判定：`real/synthetic/example`。常数或随机控制纹理是生成的 artifact，但在真实数据上的合法评估仍为 real；不能因纹理非训练而误判为 synthetic，也不能因模型名称像真实模型而把合成 ROI 升格为 real。身份识别主表的 real 结果仍要求真实有效识别器和授权数据。

训练 checkpoint 至少含可训练纹理/模块、optimizer、scheduler、epoch、update_count、best 选择指标、Python/NumPy/Torch/设备 RNG、sampler/generator 状态。固定外部网络用 hash 绑定；feature 训练保存对应骨干、训练头与优化状态，不制造 ASIT 字段。

### 7.3 恢复、复用与失效

训练默认只保证**完整 epoch 边界的确定性恢复**；未实现且验证 sampler/worker 中途状态前，从上个完整 epoch 恢复并记录重算范围，不声称任意 batch 精确续训。新尝试保存 `retry_of_run_id/resumed_from_checkpoint`。

派生任务默认整节点重跑到新目录。只有实现了按 `sample_id/pair_id/capture_id + condition + draw` 的唯一键、完整分片清单和输入 hash 校验，才允许复用已完成分片；缺片、重复片和旧键分片均不得汇总。汇总文件在所有必需片校验通过后原子发布。

阈值修正后的验证节点可复用已有原始分数，但必须验证分数生成所依赖的模型、图库、probe、pair、渲染和实现指纹一致；阈值不进入原始分数缓存键，却必须进入最终验证结果键。没有足够原始分数则重新评分，不反推样本结果。

父输出一旦 INVALIDATED，所有有该输入引用的后代立即禁止复用；新任务重新解析键，旧结果保留。报告也有父输入清单，不允许上游失效后旧表仍保持“有效”。详见自治规范的语义影响表。

### 7.4 状态与可入表条件

运行状态集合：`PENDING/RUNNING/RETRYABLE/FAILED_TECHNICAL/BLOCKED_ASSET/BLOCKED_PERMISSION/SUCCEEDED/INVALIDATED/CANCELLED_SCOPE/NOT_APPLICABLE`。

`NOT_APPLICABLE` 仅用于冻结能力规则明确不支持的组合，如无 ASIT 的 G/P/GP；保留 reason，不重试、不生成数字。资产暂缺是 BLOCKED_ASSET，零分母是指标 `INVALID_DENOMINATOR`，低 ASR 是有效测量，不能相互替代。

正式新表的每个数值单元要求：有效 SUCCEEDED 节点、real 证据、当前矩阵允许的协议/依赖、合法权重/数据、适用且有效的分母或连续指标状态、无泄漏/预算错误、所需种子完整。

`SUCCEEDED+synthetic` 只能进入测试报告，example 只能作格式演示。任务 SUCCEEDED 表示计算和校验完成，不保证每项科学指标有效；指标 null/reason 必须保留，不能因此反复训练追求非空值。

收集器按 `expected_cells` 对账：每格列出角色、比较基准、期望科学键/seed、所需指标、允许的不适用原因。正确声明的复用不是重复结果；同键多个尝试只选经验证的有效实例，不选最大 ASR。若同键产生超容差不同输出，停止复用并报告非确定性问题。

缺必需节点/seed、失效依赖或非法混合预算/能力/阈值策略时，仍输出 `coverage.json`，但以非零状态结束，标 `report_status=INCOMPLETE`，不能发布 READY 主表。合法且预声明的不适用项显示 N/A 与原因；批准取消的范围显示取消记录，不能填补数字。连续指标的合法特殊值如 PERFECT_MATCH 单独呈现，不伪装缺任务。

全部单元对账通过才可 `report_status=READY`；它仅表示证据包符合当前承诺范围，不表示所有审稿意见已充分解决。旧论文数字另列历史表，不得伪装本轮复现。
