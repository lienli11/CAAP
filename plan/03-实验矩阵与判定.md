# 实验矩阵与判定

**先登记要测什么，再看结果；先满足数据与实现门禁，再支付训练成本。**

本矩阵是 D1 前的候选设计，所有默认值都须通过可行性与资源核验。正式 manifest 冻结后，缺失单元要么完成，要么有明确范围取消记录，不能按结果好坏删除。

## 1. 共同规则

- 主任务：授权离线数据上的未定向、固定部署、掌级闭集识别；验证为同一模型的独立读数。
- 主图像：`1×128×128` 原始 `[0,1]` ROI，具体归一化绑定权重。
- 主面积：候选上限 B=784，完整形状面积在 `[0.98B,B]`，硬掩码、固定中心、标称尺度 1。
- 种子：预设 `{0,1,42}`，至少同时报告三个训练结果。不按 seed 取最大值。
- 识别器：优先 `CCNet/CompNet/CO3Net`；先完成 CCNet，其他模型必须有可信洁净基线才进入。
- 相同模型内各方法共享数据、eligibility、目标规则、评估随机流和 evaluator。
- 正式模型选择：`attack_val` 的预声明 deploy 指标，tie 选较早 epoch。测试集无选模权。
- 所有评价样本包括失败记录；明确自然退化、错误输入、捕获失败和攻击失败的区别。

旧表的协议、预算、权重或脚本不可追溯时只能作为历史报告，不与新表统计合并。

## 2. E00：只用验证集的 pilot

### 2.1 目的和候选

pilot 用于验证算法运行、学习曲线、实际成本和有限配置选择；**不用于在测试集追求更高 ASR**。

只跑 Tongji、CCNet、未定向、seed=42，每个候选一次，最多 8 个攻击训练 run：

| **候选** | **与完整配置的区别** | **回答的问题** |
| --- | --- | --- |
| P0 | 完整 ASIT + RaS + 预训练辅助项，K=1 | 起点 |
| P1 | 无 ASIT | 训练期输入条件渲染是否有益 |
| P2 | 无 RaS | 随机采集增强的作用 |
| P3 | 无辅助项 | 额外特征约束是否值得保留 |
| P4 | 辅助项随机冻结，其余与 P0 相同 | 学到的语义还是随机正则 |
| P5 | 匹配固定十字 EOT，无 ASIT/辅助项 | 直接且公平的简单基线 |
| P6 | 明确实现的通用局部 PGD | 优化基线 |
| P7 | P0 的 K=4 版本，其余不变 | Monte Carlo 采样与计算开销 |

MS-DIFE 无真实预训练资产时，P0/P1/P2/P7 的含义不能偷换；先完成预训练或标记阻塞，P3/P4/P5/P6 可独立进行。依赖由解析后的 `feature_mode` 自动生成，不靠手写候选编号判断。

预训练本身单列成本和验证记录；不计入 8 个攻击训练上限。其他超参数不展开网格，发现实现错误时修正后形成带原因的新 run，按依赖决定哪些 pilot 失效。

### 2.2 D1 冻结内容

冻结两个不同配置：`selected_caap` 是用于主表的确切模块组合；`ablation_reference` 固定含 ASIT、RaS、预训练冻结辅助项，与主方法共用已选 K、数据、预算、优化器和最大更新数。主方法删除模块不改变这个参考配置。若预训练资产始终缺失，只能明确取消相应科学问题并收缩主张，不能把随机特征改名成完整参考。

E03 固定五行：`reference`（无改动）、`reference_no_asit`（仅关 ASIT）、`reference_no_ras`（仅关 RaS）、`reference_no_feature`（仅将辅助项改 none）、`reference_random_feature`（仅将辅助项改 random_frozen）。每行保存 `base_config=ablation_reference,overrides,compare_to=reference,reuses_scientific_key`；覆盖后的完整配置相同才能去重。主方法选成无辅助项时，仍保留 reference 与 random/pretrained 的三种子比较。

冻结 K、RaS/ASIT 范围、最大更新数、早停规则、调参次数、计算上限和全部评价条件。矩阵展开测试必须覆盖主方法已关 ASIT、已关 RaS、已关辅助项三种情况；基准行不丢失，添加模块不能标为“移除模块消融”。

K=4 仅在预设 pilot 预算内比较；既看验证表现也看成本，不以测试图选择。若开启新几何 EOT，作为独立协议因子，不与改 K 同时变化后单独归因于 K。

输出：`protocol.json`、`experiment_manifest.json`、估计资源表、未解决资产清单、独立审查意见。用户只需在 D1 决策一次，不逐个 run 批准。

## 3. 核心正式矩阵

### 3.1 训练单元

| **编号** | **设计** | **候选新增训练数** | **优先级** |
| --- | --- | --- | --- |
| E01 | Tongji × 3 掌纹模型 × 3 方法（主方法、匹配十字 EOT、通用局部 PGD）× 3 seeds | 27 | P0 |
| E02 | CCNet × 3 额外形状（完整方/圆/三角）× 3 seeds，十字复用 E01 | 9 | P0，机制起点 |
| E03 | CCNet × reference/无 ASIT/无 RaS/无辅助项/随机辅助项五行 × 3 seeds | 最多 15；与 E01 严格配置去重 | P0，组件证据 |
| E04 | E02 扩展到另外 2 个掌纹模型 | 18 | P1，支持跨模型机制 |
| E05 | 预设同跨度控制及方向模板，CCNet，3 seeds | D1 固定模板数后计算 | P1 |
| E06 | IITD 上复制 E01；AISEC 如有资产另列 | 每数据集 27 | P1；不直接全做 |
| E07 | 少量真实目标的定向固定部署 | 按目标数×方法×模型×seed 明列 | P2 |
| E08 | 四通用 CNN、集成留出、新骨干、防御扩展 | 单独预算 | P2 |

核心候选上界 **51 个攻击训练 run**（E01–E03），不含识别器训练和 MS-DIFE 预训练。主方法与 E03 某行相同时通常可复用 3 个 run，降至 48 或更少，准确数由科学键展开器给出。pilot 与正式配置、训练预算、数据均一致且在冻结前明确允许复用时才复用，不事后挑 pilot 好结果。

资源不足时在 D1 前把核心范围缩到单模型，保留直接基线和三 seed；此时不可保留“三个模型均成立”主张。不能在读到最终测试结果后挑最有利模型缩范围。

完整 `2³` 模块组合可作为 P1 扩展；E03 的有限消融不足以估计所有交互效应，论文不可声称已分离所有三阶交互。

### 3.2 不另训的派生评估

E01–E03 的每个有效 artifact 根据能力声明派生以下节点，各有独立科学键和父 artifact hash：

- 全部执行固定部署；仅含 ASIT 的 artifact 执行条件渲染。H1 的 reference 必做 D/G/P/GP 及 `scale=fixed_one/predicted` 诊断；无 ASIT 的对应节点为 NOT_APPLICABLE，不计实验失败。
- 标称 clean、训练分布内留出 seed、平均模糊 `5×5`、gamma 1.8、JPEG Q40；这些是预设数字条件，不代表相机穷尽模型。
- 同条件 clean/adv，逐样本支持面积和失败记录；随机多 draw 采用契约规定的池化条件率，宏平均单独命名。
- 固定图库与校准阈值下的验证；校准节点每 model/gallery/calibration/pair-rule 仅生成一次，所有 patch 方法引用同一 threshold hash。
- 线结构覆盖代理、视觉指标和分类/验证联合计数，均为独立派生节点。
- 每个实际 mask/placement 创建常数灰度、白纸样和固定 seed 随机纹理 artifact，`train_seed=null`，按生成科学键去重，不伪造训练 checkpoint。
- E01 的固定部署同域跨模型评估：`source != target`，3 source × 2 target × 3 方法 × 3 seeds = 54 个 eval 节点，不另训；范围缩为单模型时显式不适用。跨域评估另以 E06 可用资产和 D1 范围展开。

可追加轻/中/重退化曲线，但等级、组合数和主终点必须在测试前冻结。不能看到 Q40 结果不好就换成 Q70 作为主结论。

## 4. 机制矩阵：怎样控制替代解释

### 4.1 形状与跨度

E02 测的是匹配面积下的**几何总体差异**，仍混合外接跨度、周长与方向。若只完成 E02，不写“已证明主线机理”。

E05 必须先生成全部 mask 描述量：完整十字、条带/稀疏控制的面积和外接框尽量匹配；无法匹配的变量列表写进协议。离散可行性在训练前检查，不能训练后换模板。

方向候选由训练前固定模板构成，逐模板优化相同通用纹理训练流程。测试时一张 artifact 对所有图相同，不允许选最合适方向。

主要分析：配对 ASR 差、效果与 coverage 的关系、控制跨度后的描述性模型、跨模型方向一致性。可用 Spearman/逻辑回归辅助，但不能把相关系数当因果效应，也不能把同一 patch 的所有 sample 当独立 patch 复现。

### 4.2 视觉与可制造性

每个 artifact 输出未归一化灰度图、掩码、局部和全图 MAE/PSNR/SSIM、TV、物理导出尺寸。指标实现的归一化和零误差边界需测试。

全图指标会被小面积稀释，必须有 patch 支撑附近的局部读数。灰度复制三通道的 LPIPS 只能作为适用性受限的附加指标，不能自动宣称感知不可见。

`[0,1]`、低 TV、较高 SSIM 都不直接证明打印色域或不可感知。没有人评/打印标定时，正文用“局部、面积受限”而非“不可察觉”。

## 5. 迁移与定向设置

### 5.1 跨模型/跨域

源 artifact 只由源模型、源数据和源验证选择。目标模型在独立 evaluator 才出现，训练/选择过程不查询目标梯度、输出或 ASR。

同域跨模型至少给 source→target 非对角矩阵。跨数据集时，补丁迁入目标域的**独立有效识别器**，使用目标域类别映射/图库；不能把 Tongji 的 600 类头直接当 IITD 的 460 类身份语义。

源模型自有条件分母与目标模型条件分母分别保存；表注说明以目标 clean-correct 为分母。跨域识别器本身崩溃时不把剩余极小分母解释为强迁移。

### 5.2 定向

类 0 仅在有真实样本和对应目标模板时合法。优先由固定 seed 从合格训练/注册身份中选至少 3 个目标；若预算只允许 1 个，必须称单目标研究，不概括目标可控性。

目标挑选不使用测试 ASR。目标库不使用测试图；跨数据域的相同数字 class ID 不代表同一个人，定向跨域默认不开展。

最终定向 ASR 低不是技术故障，不自动停止/换目标后仅保留成功目标。D1 冻结了几个目标，就完成或明确取消整个预注册范围。

## 6. 物理证据分支

### 6.1 旧数据恢复

原稿声称的 400 张原图、capture→subject/palm/attempt/patch 映射和模型版本找回后才可重算。只找回图 5 的 9/10 不可逆推出逐次结果。

不同打印物、黑白/RGB、攻击模式与模型分别分析；20 次合并若跨多种打印物，明确是物体集合加重试的结果。

### 6.2 经许可的新对照

默认五组：洁净、同形状常数遮挡、匹配固定十字 EOT、`ablation_reference`、`reference_no_ras`。这样即使 `selected_caap` 已关闭 RaS，也仍保留真正只改变 RaS 的物理对照。主方法若不同于这些 artifact 且需要主方法实拍结论，D1 前另加第六组；不能把不同模块配置的两张纸称为无 RaS 消融。其他物理 ASIT 消融如有余量另加 `reference_no_asit`，不以改变多个组件的 EOT 行冒充纯 ASIT 消融。

所有物体使用相同名义物理面积和登记尺度；常数遮挡的材质也记录。若获准沿用 10 人、每组每人 10 次、一个攻击模式、一个标称工况，五组计 **500 次采集**；额外每组加 100 次。增加第二模式、设备、条件或打印物需重新计算，不能隐去这些成本。

条件采集顺序尽量随机交错，登记操作者、时间与位置偏差，避免光照/熟练度随组顺序变化。增加 `15°` 姿态等是独立受限条件，不声称全条件泛化。

任何新增拍摄均需要真实许可和人员实施；Agent 只处理计划、表格、校验和评估。未经许可不联网抓取人体数据、不替换受试者、不生成假成功。

## 7. 统计与预设解释

主终点在 D1 选定：建议未定向 deploy ASR 与匹配十字 EOT 的配对差；其余验证、机制和物理结果各有明确 secondary/exploratory 标签。

每 seed 单独 `k/n`、mean/SD、固定 artifact 的身份聚类区间同时报告。主要方法差在相同 identity 和 seed 下配对；多个比较若给显著性检验，应使用预注册家族和 Holm 等控制，不只展示显著单元。

没有事先功效分析时，不能用 CI 跨 0 宣称方法等价，也不能用 2 个百分点以内声称“模块无用”。三 seed 的离散度主要是稳定性描述，不支撑夸大的统计功效。

| **结果** | **允许的解释/动作** | **禁止动作** |
| --- | --- | --- |
| 条件渲染高于固定部署 | 报配对差并查面积/光度因素 | 放宽测试变换让差更大 |
| 差为 0 或负 | 报告当前条件下无优势/固定更强 | 强行把 oracle 写为上界 |
| 等跨度控制后十字优势消失 | 缩小拓扑解释 | 恢复不等面积旧表 |
| coverage 无稳定关联 | 假设未获支持 | 换测试滤波器直到相关 |
| RaS 数字有益但实拍缺失 | 只写数字证据 | 标记物理消融已完成 |
| MS-DIFE 无稳定增益 | 保留消融，按验证决策简化主方法 | 换大网络追最终测试分数 |
| 分类 ASR 高、目标接受低 | 当前分类攻击不等于同等认证风险 | 声称系统安全或可被冒名登录 |
| 实拍旧数据无法恢复 | 物理条目标部分解决并收缩结论 | 从汇总比例制造 CSV |

## 8. 资源估算与停止

pilot 记录每配置 warm-up、有效更新耗时、峰值显存、eval 开销、预训练与 I/O。估计总成本为各 job 测得成本之和，加一次受限技术重试储备；储备比例和总上限在 D1 批准。

最大并发按实际获准 GPU 和显存决定，默认每卡一个训练任务。任一主协议修改先停止派发受影响的新任务，旧结果打失效标记；不会只重跑 CAAP 而保留旧基线。

预算不足时按 `doc/04-三周计划.md` 缩范围，在最终测试前确认。已看最终测试后只能解释结果和修复可证明的技术错误，不能无限扩展实验直到出现满意结论。
