# 全量实验矩阵与判定

**先登记覆盖，再看结果；先通过开发与计算门禁，再支付训练成本。默认 `scope=full`，旧 core 仅作分批成本参考。**

本文件是 future 科学执行合同，不表示本轮已开始训练。F01–F45 规定实现任务，实验单元由冻结 `experiment_manifest.json` 展开；任务完成数量不能替代科学单元覆盖。

## 1. 共同规则与资产面

- 数据集：Tongji、IITD、AISEC 全部登记，不能因路径不存在直接略过后两者。
- 模型：CCNet、CompNet、CO3Net 和原稿四个通用 CNN 全部登记；使用实际类与权重来源，不以名字冒充标准 torchvision 实现。
- 任务：分类未定向、多目标定向；认证本人拒绝、目标接受。原分类 artifact 的认证评估与 verification 专用损失分开。
- 主图像：`1×128×128` 原始 `[0,1]` ROI；模型归一化绑定权重，不支持尺寸需适用性审计。
- 主面积：候选上限 B=784，完整二值形状面积 `[0.98B,B]`，硬掩码、固定中心、标称尺度 1；`legacy759` 单列。
- 训练种子预设 `{0,1,42}`，同时报全部点/mean/SD，不选最好 seed；方法共享合法角色、eligibility、预算解释与评估随机流。
- `attack_dev/attack_select` 上的所有观察与搜索计入账本；final 无选模权。历史测试曝光继续披露，不靠重命名恢复“未见”。

每个数据集×模型先生成资产/能力单元：有可信权重则审计与 clean 复评；没有则在真实获准 `recognizer_fit/recognizer_val` 上训练、选模和保存可恢复 checkpoint。没有数据/许可时标阻塞，不能用随机权重填主表。

F09开发的registry-ready要求21条清单/状态结构齐全，不要求21个模型已经全部验证；F20可保留完整full清单并冻结已就绪子图。每个scientific cell只绑定自己的dataset/model registry entry、角色、feature/recipe、branch freeze和预算。AISEC未知不阻塞合法Tongji单元；全registryhash用于追溯，局部条目hash进入科学键。缺项始终保留pending/blocked，不能通过缩小注册表提高full完成率。

不支持 embedding、防御或认证算法的模型，保留格子并完成适用性报告，区分理论不适用、需合法适配、当前未实现、缺资产。只有冻结科学范围预声明且经审查的真实不适用才允许 N/A；不以代码没写、运行太贵或 ASR 低为 N/A。

## 2. 有限探索、pilot 与冻结

### 2.1 观察与搜索权限

`observational phase` 可先在已有读取权限内做环境、目录、来源和 manifest 审计，无需先获得训练许可；不训练，不执行未知资产代码，不读取 final 评分。访问新受限路径、联网或安装仍需要对应许可。

有测量/计算授权后，在非 final 小任务上测 warm-up、step/draw、I/O、评估耗时和峰值显存，再核算 full 预算。训练不得以“测时”名义绕过 G1/G2 或 allocation。

探索预算明确 `candidate_space,max_trials,max_updates_per_trial,max_gpu_hours,stop_rule,selection_metric`。允许在 attack_dev 观察 loss、数值错误与有限超参；attack_select 选择候选/epoch，日志包括失败和被放弃候选。有独立 attack_confirm 时仅按预设次数确认冻结方法，不依据确认结果无限改法。

source-only 迁移的候选选择只能读源域/源模型数据；目标攻击结果即使存储可访问，也不得反馈搜索器。使用目标 dev 选法必须另命名 target-informed 分支，不能仍声称 source-only。

### 2.2 保留的 core pilot 参考

旧 E00：Tongji、CCNet、未定向、seed=42，最多 8 个候选攻击训练，是可复用的初始观察子计划，**不是 full 搜索域或终止上限**。

| **候选** | **与完整配置的区别** | **问题** |
| --- | --- | --- |
| P0 | ASIT + RaS + pretrained_frozen，K=1 | 参考起点 |
| P1 | 仅关闭 ASIT | 输入条件训练是否有益 |
| P2 | 仅关闭 RaS | 随机采集增强作用 |
| P3 | 仅关闭辅助项 | 辅助项贡献 |
| P4 | 辅助项改 random_frozen | 学到的特征还是随机正则 |
| P5 | 匹配固定十字 EOT | 简单公平基线 |
| P6 | 通用局部 patch PGD | 优化基线 |
| P7 | P0 仅改 K=4 | Monte Carlo 与成本 |

MS-DIFE 无权重时先用 patch_train 内层 msdife_fit/msdife_val 预训练，单列费用和记录；不能把随机模式改名 pretrained。依赖按解析配置生成。K 次损失取均值，改变几何 EOT 需独立因子，不能和 K 同时变后只归因于 K。

### 2.3 D1 冻结

分别冻结主方法配方与 `ablation_reference`：后者始终含 ASIT、RaS、预训练辅助项。主方法删除模块不改变参照。`selected_caap` 仅是显示别名，不能作为所有 source-only 任务的唯一全局搜索结果。

F20 为迁移预注册两种且只能据实际证据选择的配方来源：

- `selected_caap_by_source[source_spec_id]`：source_spec_id 明确源数据域与源模型集合（含集成成员）；每源只使用该集合的 patch_train/attack_dev/attack_select 选择方法、模块、K、辅助网络、基线超参与 checkpoint。
- `a_priori_shared`：在本研究目标模型/域反馈出现前完全事前固定的共享配方，记录冻结来源与时间证据；不能将已经用 Tongji/CCNet pilot 调过的配方再改名为事前固定。

每份配方保存 `recipe_origin,selection_manifest_hash,selection_visible_sources,selection_evidence_refs`，由这些输入绑定训练科学键。`ablation_reference` 和匹配基线同样携带选择谱系。仅在数值配置、选择谱系与其他科学输入全部相同才跨表去重；来源不同却数值偶合不是无条件复用依据。

冻结角色/历史曝光、目标集合、能力/模板/阈值权限、更新/EOT/查询/调参预算、主次终点、种子、退化/物理条件、预期单元、N/A 规则、资源上限及技术重试储备。

输出协议与 hash、完整范围 manifest、成本/权限表、独立审查与缺口。F20 是数字全局冻结，不以认证原文/旧实拍恢复为所有数字任务的硬门禁；F23 的独立 matched EOT/PGD 也不等待 F22 原代码取得。原法复现和外部分支的阻塞格始终保留在 full 范围与 F43 最终对账中。

已授权的探索范围内不逐候选询问；协议/预算的关键新增或修改集中 D1 决策。各分支仅在自身许可、开发门禁与独立确认数据满足后冻结和执行，任何分支的 final 都不能反馈其他分支方法设计。

F33 新架构/集成、F35 对抗训练、F36–F37 认证、自适应攻击与 F39–F42 物理链均采用 **阶段 A 开发/观察 → 分支 freeze → 阶段 B 独立确认**。开发门禁可依赖合法 development/pilot 证据，不能要求先看最终实验结果再设计算法；确认角色一旦曝光就记账。要求独立确认的分支缺确认集时阻塞确认结论，不能利用一般 attack_confirm 可选条款绕过。

原实拍或原基线资产盘点可完成并留缺口；盘点 gate 不等于真实恢复/原法复现完成。无关数字开发可继续，full 最终对账仍保留这些阻塞格。任何分支都不能根据已看 F24/F32 final 结果重选架构、防御或打印物。

### 3.2 完整组件组合

完整因子表为 `ASIT ∈ {off,on} × RaS ∈ {off,on} × feature ∈ {none,pretrained_frozen}`，共 8 行。

对 feature=pretrained_frozen 的 4 行，各增加仅替换为 random_frozen 的控制，因此每个冻结模型/数据条件最多 12 种配置；完全同键才去重，random 与 pretrained 不能因维度相同合并。完整表支持预声明交互项分析，但统计支持不足仍需标记。

旧 E03 的 `reference/no_asit/no_ras/no_feature/random_feature` 五行继续作为最低回归子集；即使 selected_caap 已关闭任一模块，这五行仍在。它们不能代替 full 的全部组合。

## 4. 派生任务与机制控制

每个 artifact 按能力生成独立科学键：固定部署、合法条件渲染、分类/验证、视觉/结构和跨模型评估。校准每 model/gallery/calibration/pair-rule 共享一次，不为每个补丁重选阈值。

- H1 的 reference 必做 D/G/P/GP 与 `scale=fixed_one/predicted`；无 ASIT 的对应条件为预声明 N/A，不制造恒等结果。
- 基础数字条件保留标称、训练分布内留出 seed、平均模糊 `5×5`、gamma 1.8、JPEG Q40；轻中重档位/组合在 G3 前补全冻结，不能见 Q40 差就换主条件 Q70。
- 各 mask/placement 生成常数灰度、白纸样、固定 seed 随机纹理，`train_seed=null`；真实数据上的这些控制评估仍可为 real。
- 退化的 clean/adv 使用相同 draw，主随机 ASR 为有效 draw 池化率；probe 宏平均、标称固定集合、多数投票和重试分别命名。

等面积方/圆/三角/十字仍混合跨度、周长、方向。full 另做同跨度控制与固定方向/位置模板；离散不可匹配的因素在训练前公开。位置不得由测试 attention、标签、梯度或 coverage 在线挑选。

线能量代理不使用 victim 权重/标签；报告配对差、原始点、跨度控制和设计秩。模板/簇不足输出 `INSUFFICIENT_DESIGN`，不能删除协变量以得到期望系数。

外观报告 `[0,1]` 灰度纹理/掩码、局部/全图 MAE/MSE/PSNR/SSIM、有效邻边 TV 与打印尺寸。小面积稀释、PSNR 无穷状态、局部区域大小全部按 01 合同。LPIPS 如开展须单列灰度适配限制；低 TV/高 SSIM 不证明不可感知或可打印。

## 5. 转移、定向与防御

### 5.1 迁移

七模型同域至少包含全部非对角 source→target 单元；三模型 core 的 54 个派生 eval 只是一部分。每个目标模型必须有独立有效 clean 基线和类别映射。

F32 不能无条件复用 F24 全部 artifact 并称 source-only。每条边须验证配方的 selection_manifest_hash、可见源集合和递归训练/调参证据，target 与这些上游选择依赖不相交才可复用。全局七模型或三域聚合选法会使相关目标成为 target-informed；Tongji/CCNet 单源 pilot 配方对其他 source→CCNet 同样不能冒充无目标反馈。审计失败时为 source-only 重新按合法源配方训练，或留下缺口并将现有结果单列 target-informed。

集成训练冻结源集合、权重和留出目标，目标绝不参与候选选择；留出不是事后把表现差模型剔除。跨域迁移不得把 Tongji 类别头直接解释为 IITD/AISEC 身份；目标域 clean 失败则阻塞有效性，不用极小分母掩饰。

新增架构经能力/训练/洁净基线审计后进入预注册迁移族，不能仅凭一个未训练前向当已覆盖。若允许 target-informed 适配，使用独立任务/预算/名称，不能污染 source-only 主表。

### 5.2 定向和验证目标

每个数据域默认至少 3 个由固定 seed 从合法训练/图库身份选出的真实目标；所有目标、同人双掌处理、模板和抽样规则在 final 前冻结。类 0 不是天然有效目标。

同数字 class ID 跨域不代表同一身份。定向跨域仅在存在合法且明示的跨域目标定义时展开，否则做适用性审计，不能填虚构目标。单目标只能形成部分、单目标结论，不能冒充 full 多目标。

本人拒绝与目标接受使用 01 §5.3 的专用损失和权限矩阵。低目标接受率是当前攻击的负结果，不等于认证系统安全；不换目标或扩大模板访问来“修复”科学结果。

### 5.3 防御与认证

对抗训练必须有真实 `train_defense` 节点：训练攻击集合/预算、clean/adv 混合、合法 fit/val、选模、checkpoint 和成本。防御后 clean、攻击后性能及必要认证指标共同报告，不能把随机初始化或未训练模型叫对抗训练。

PatchCleanser/CertMask 分别审计原实现、许可证、骨干要求、输入变换、mask/patch 威胁域、算法随机性、推理代价和认证条件。允许适配时清楚命名，提供等价或限制证明；不支持时留有原始问题/适配任务，不能删格。

`certify` 输出逐样本预测、认证通过/未通过/不适用原因、证书威胁集合与耗时。认证失败不等于发现攻击，经验攻击失败也不等于获证。威胁范围超出保证时不能把认证数值写成该范围鲁棒率。

## 6. 真实物理证据

旧原稿声称的 400 张原图、capture→subject/palm/attempt/patch 和模型版本恢复后才可重算；图 5 的 9/10 无法反推出逐次 CSV。黑白/RGB、打印物集合、模型、模式、目标分别分组。

新采集保留洁净、同形状常数遮挡、匹配 EOT、reference、reference_no_ras 五组；selected_caap 不同且要做其物理主张时加组，ASIT 物理消融用 reference_no_asit 而非同时改变多个组件的 EOT。

full 同时覆盖**多设备、姿态、距离、光照、位置**，每维至少有预先登记的多个实际水平及共同标称条件；具体设备/单位/水平数、必要交互组合、每格人数/次数与实际可实施性在采集前冻结。五组×10 人×10 次=500 次仅是一个模式、设备、标称工况的 core 示例，不等于 full 总量。

逐次交错随机采集，记录时间、操作者、patch_id、材质、物理尺度和实际位置偏差；真实 ROI 经 `preprocess_capture` 固定算法后由 `score_capture` 评分，不根据成功率挑 crop。保留捕获/预处理失败和全部尝试。

顺序 ASR@1/5/20 需要真实时间顺序和足够次数；不足为 null，不能用随机子集或独立假设公式代替。单次、按人宏平均、全流程成功与条件识别率、聚类区间分开。

数据同意、伦理/许可及人员实施属于外部依赖。Agent 可准备采集表、校验和评分，不能代替人类拍摄或宣称外部许可会自动解决。

## 7. 统计与预设解释

各实验族冻结主/次/探索终点。可建议以未定向 deploy 相对匹配 EOT 的配对差为主终点之一，但验证、机制、防御和物理不能因此从 full 删除。

逐 seed 的 k/n、全部点、mean/SD 与固定 artifact 的身份聚类区间同时报告；验证按 pair 双端 multiplicity 处理，单一固定目标按合同限定泛化。多重检验有预注册家族与校正，不只展示显著单元。

CI 跨 0 不证明等价；没有功效支持不能用任意 2 个百分点阈值宣称“模块无用”。只许预注册的样本扩展/停止规则，不能加 seed/人直到显著。

| **结果** | **允许解释** | **禁止动作** |
| --- | --- | --- |
| 条件渲染高于固定部署 | 给配对差、面积/光度分解 | 把 oracle 当必然上界 |
| 差为零或负 | 当前无优势/固定更强 | 扩测试能力追优势 |
| 等跨度后十字优势消失 | 缩小拓扑因果解释 | 恢复不等面积旧表 |
| coverage 无稳定关联 | H2 未获支持，保留设计诊断 | 换测试滤波器追相关 |
| RaS 数字有益、实拍未得 | 仅有数字证据 | 称物理消融完成 |
| MS-DIFE 无稳定收益 | 阴性消融仍是有效结果 | 换教师追 final 分数 |
| 分类成功、目标接受低 | 两类风险不等同 | 声称已冒名登录或系统绝对安全 |
| 认证失败 | 未获该威胁域保证 | 直接称存在成功攻击 |
| 实拍/许可缺失 | 部分完成与恢复条件 | 生成假原图、预测或 CSV |

## 8. 预算与停止

总 GPU-hours 由识别器/辅助/补丁/防御训练、校准、派生评分、认证及技术重试按实测求和；显存、存储、CPU/RAM、I/O 和采集人时另列，不用训练 run 数掩盖派生费用。

在获准 allocation 内先单设备测量，再按依赖/独占租约并行；DDP 非默认，未经等价/恢复/吞吐测试不得开启。空闲显存不是授权，不能绕 Slurm。

资源不足先停止新派发、保全 checkpoint 与有效证据，集中申请追加预算或输出部分交付。取消范围可形成新 scope，但原 full 的未完成格保留；不再引用三周时间表作为自动删减依据。

最终测试后只修复可证明技术错误并一致重跑所有受影响方法；不可把最终反馈变成新搜索。`execution_exhausted` 和 `full_scope_complete` 的区别由 06 严格判定。
