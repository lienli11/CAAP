# 全量覆盖与完成判定

**完成表示冻结范围被真实证据回答，不表示所有结果支持 CAAP。预算耗尽、代码通过或缩小 scope 都不能替代 full 完成。**

本文件是 future 对账标准，本轮没有生成正式科研证据。审稿编号沿用 [审稿意见源摘要](../doc/02-审稿意见.md) 和 `paper/sources/review-letter.pdf`：R1 七条、R2 五条、R3 四条，共 16 条；H1–H5 是研究假设而非额外审稿原话。

## 1. 三种终止状态与四种交付事实

| **状态** | **满足条件** | **不能表示** |
| --- | --- | --- |
| `full_scope_complete` | 原始 full manifest 的所有必要计算/分析/稿件单元按合同决算，合法 N/A 有审查，证据/限制/复建均通过 | 方法一定优于基线、论文一定接收 |
| `execution_exhausted` | 当前可执行队列、预算、时间或同根因重试额度耗尽 | full 单元全部完成 |
| `partial_blocked` | 尚有外部资产、许可、采集、实现、依赖或稿件缺口 | 阻塞等于阴性结果，或未完成可填 0 |

同时记录四条独立状态：**代码已实现、测试已通过、真实实验已完成、论文已修改**。某 F 任务的 development 验收与真实 evaluation 分开；当前 doctor/plan-check 的成功不能提升科学计算状态。

`full_scope_complete` 为逻辑合取：范围身份未被偷换、全部必要有效单元存在、预声明不适用审计有效、全部审稿/假设有相符证据与稿件动作、恢复/复建与隐私检查通过。低 ASR、负差或假设未获支持，只要证据满足该问题的设计要求，仍能完成相应研究问题。

## 2. full 覆盖基线

| **维度** | **必须在冻结清单中出现** | **最低完成证据** |
| --- | --- | --- |
| 数据与识别器 | Tongji/IITD/AISEC × 七原稿模型 | 21 个资产/能力单元，真实来源/训练分支、clean gate 与角色曝光 |
| 分类 | 未定向 + 至少 3 个合法预设目标；全部模型/数据/方法/seed | 逐样本 clean/adv、k/n、全部 seed 与目标，不选最大 ASR |
| 验证 | 本人拒绝/目标接受；原分类驱动与验证专用驱动 | 图库/校准/权限、阈值、逐 pair、联合风险与双端统计 |
| 基线与组件 | 原法及匹配适配、完整 `2³`、无/随机/预训练 | 原法许可/能力/差异、固定更新与成本账本、全因子格 |
| 机制与位置 | 面积、跨度、周长、方向、位置、大小和软边 | 合法 mask、固定代理、可识别设计、配对结果 |
| 迁移 | 七模型 `7×6` 非对角/域、集成留出、三域 `3×2`、新架构 | source-only 访问隔离、目标自有有效模型/映射、无删格 |
| 防御 | 对抗训练、PatchCleanser、CertMask | 真实防御训练、定理/能力审计、认证与旧/自适应经验攻击分离 |
| 物理 | 多设备/姿态/距离/光照/位置 + 五组必要对照 | 许可、真实捕获/打印/ROI/预测、逐次失败与顺序重试 |
| 文稿与复建 | 16 条审稿、H1–H5、方法/符号/引用/图表 | 每项状态/证据/页节/限制，干净环境重建报告 |

原始 full manifest 的 hash 与 expected_cells 永久保留。某项缺数据、许可、预算或实现时保留 blocked 格；不得以“该型号不方便”“效果不好”“文献暂未获得”作为科学 N/A。

确实不支持的组合必须有定理/接口/任务定义层面的适用性证据、预注册处理与独立复核。能合法适配的先形成适配任务；不能把整个七模型验证/防御矩阵删成一个成功模型。N/A 不生成数值，也不被用来替代本来承诺的独立研究问题。

审稿“解决”不是自动接受判断。只有意见实际要求的证据与相符改稿齐备，才能标 `addressed_with_evidence`；诚实披露尚缺实拍/模型仍是 `partially_addressed/blocked`，不能因为回复已写就升级。

## 4. H1–H5 假设与判定

| **假设** | **预注册问题** | **最少有效证据** | **不支持时的结论** |
| --- | --- | --- | --- |
| H1 | 测试输入条件渲染与固定部署差异来自哪些几何/光度因素，训练 ASIT 是否仍有效 | F12/F17/F25/F26：同 artifact D/G/P/GP、共同 ID/draw/eligibility、fixed_one/predicted 面积、有/无 ASIT 独立训练后共同 D | 差可为 0/负；不称 oracle 上界，不扩大测试权限 |
| H2 | 十字表现与独立线能量覆盖相关，还是面积/跨度等混杂 | F13/F27–F29：固定无 victim 代理、等面积/同跨度/方向/位置控制、簇/秩诊断和全部点 | 优势消失或无稳定关联即缩小机制主张；设计不足与阴性分开 |
| H3 | 分类错误与本人拒绝/目标接受是否一致，验证专用攻击改变什么 | F15–F17/F24/F30：原分类与两种验证驱动、冻结模板/阈值/权限、共同集合 2×2、clean/adv FMR/FNMR、target acceptance | 不同风险可分离；低当前攻击风险不证明系统安全 |
| H4 | RaS/K 的数字增益能否延续到留出条件与真实物理 | F26/F31/F39–F42：K=1/4 固定更新/等计算、同分布新 seed/留出轻中重条件、纯 no_ras 实拍对照 | 只有数字有效则只能声称数字结果；缺实拍不是“泛化成立” |
| H5 | 固定支撑攻击与 PatchCleanser/CertMask 等保证的适用边界是什么 | F13/F21/F35–F37：原定理/实现/输入假设、范围内外支撑、逐样本证书、旧/自适应经验攻击与成本 | 超范围成功不击破定理；未认证不等于已攻破，范围内矛盾须独立复核 |

H1–H5 可标 `supported/not_supported/mixed/inconclusive_design/blocked`，与执行成功分开。必要设计已经完整且结果为 not_supported 可以完成；缺关键证据的 blocked 或无法回答问题的设计不足不能伪装“阴性完成”。

## 5. 每格证据清单

正式 `coverage.json` 的每格至少列出：

- `cell_id,scope_id,original_full_manifest_hash,question_ids,comparison_refs`：明确它回答哪个 reviewer/H/主张，不以表格显示名代替科学身份。
- `expected_task_type,expected_scientific_key,seed,objective,source,target,condition,applicability`：所有预设格在结果出现前登记。
- `development_gate,evaluation_gate,protocol_hash,branch_freeze_hash`：开发通过与真实计算授权分开。
- `run_id,parent_hashes,artifact_hashes,evidence_type,validation_status`：完整父链、代码/环境、合法数据/真实模型和唯一有效实例。
- `runner_registry_hash,execution_prerequisites_hash,dependency_bindings_hash`：证明文档依赖已转换为明确开发/证据门禁和科学输入，不凭 F status 推断可执行。
- `recipe_origin,selection_manifest_hash,selection_visible_sources,selection_evidence_refs`：source-only 每边审计传递选择闭包；目标参与过全局配方选择时只可单列 target-informed，不填 source-only 格。
- `sample/pair/capture_refs,eligibility_hash,k,n,rate,unit,interval_method`：连续指标可不含 k/n，但类型/schema 必须明确；null/完美匹配等边界按合同保留。
- `actual_cost,retry_of,invalidated_by,reuses_scientific_key`：真实资源、重试、失效和合法跨表复用，不增 seed/样本数。
- `status,reason,remaining_action,manuscript_location`：成功、阴性、无效、缺失、失败、N/A、取消分别说明。

train_* 必须有完整 checkpoint/选模记录；run_original_attack 按原法 state_contract 验收，没有optimizer的原法不伪造训练状态。calibration 必须有干净分数/阈值；certify 必须有保证前提/逐样本证书；export_print 必须有源artifact、DPI/尺寸/设备/材料/标定和输出hash。物理证据将实际打印物绑定到该导出，再形成 raw capture→ROI→模型预测链；导出文件本身不能证明已经打印/拍摄。只留聚合 ASR、截图或手填成功标记不能满足。

## 6. 阴性、失败与不适用的区分

| **情况** | **计算判定** | **覆盖动作** |
| --- | --- | --- |
| ASR 低、差为负、模块无稳定收益 | 技术校验通过即可 SUCCEEDED | 报全部结果和不确定性；不为效果重试 |
| n=0、全拒绝阈值、统计支持不足 | 任务可完成但相应指标 invalid/null | 保留原因；关键问题未回答时覆盖仍不足 |
| 缺 seed、损坏 checkpoint、失效父链 | FAILED_TECHNICAL/INVALIDATED | 有限重试或恢复，不以负结果顶替 |
| 缺合法数据/真实权重/设备或许可 | BLOCKED_ASSET/BLOCKED_PERMISSION | 走真实训练/补给或等待授权，不能 synthetic 顶替 |
| 模型/定理确实不适用 | 经预声明/审查的 NOT_APPLICABLE | 保留原格和证据，不填 0、不反复派发 |
| 实现尚未支持某接口 | 开发未完成 | 不能写理论 N/A 来跳过 |
| 用户明确缩小范围 | CANCELLED_SCOPE，产生新 scope | 原 full 缺口仍存在，不把删除格计完成 |

范围内证书与经验成功矛盾、泄漏、标签错误、面积越界或 unauthorized GPU 等异常先保全证据并停止受影响节点。证明是技术错误后修复，按依赖一致重跑所有受影响方法/seed/条件；不能只改对主方法有利的一侧。

## 7. 完成算法与发布门禁

1. 从**原始冻结 full** expected_cells 枚举全部必要项，加载当前版本与分支 freeze，而不是只扫描存在的 run 目录。
2. 逐格验证能力/权限、数据角色、父输出、科学键、全部 seed、类型化产物和指标；同键多个尝试按有效性选，不按 ASR 最大选。
3. 合法别名复用仅算一次计算、映射到多个预设格；非法 N/A、scope 取消和例子/合成证据不得提升 full 实证覆盖。
4. 对 16 reviewer 与 H1–H5 分别聚合必要证据及未解子问题，校验稿件位置、结论强度、失败/限制说明。
5. 检查资源账本、恢复/干净重建、保密与公开边界。论文源码缺失只能给改稿建议，不能称已编译或已修改正式稿件。
6. 始终输出 coverage 与缺口；任一必需缺口使 full 报告 `INCOMPLETE` 且非零退出。全部满足才发布 full `READY` 并将 full_scope_complete=true。

旧 core 的 READY、8 个 pilot、51 个训练、全部 F “代码已写”或“没有可领任务”都不能绕过第 1 步。用户批准 scope 缩减可以得到诚实的局部 READY，但必须保留 `original_full_complete=false` 与取消记录。

## 8. 最终交接包

证据报告交付在 `reports/` 下，包含完整覆盖/主张/逐条回复、有效/失效 run、全部阴性与失败、资源消耗、外部资产补给条件、当前 revision/环境 lock 和唯一续跑入口。取得合法源码后的修订稿与编译输出仅写 `paper/revision/`；`paper/sources/` 始终 immutable，原文 hash 只读引用。公开材料仅含获准的匿名统计与可复现配置，不泄露生物模板、个人映射或私有路径。

F45 的干净重建验证不要求无理由重训全部模型；优先在新获准工作区读取合法既有产物、重新校验依赖并重建相同表格，另做有限恢复烟测。未提交重构不能说远端能 clone 到；发布/投稿/commit/push 仍需用户明确授权。

终止摘要同时回答：“完成了什么、证据在哪里、哪些结果不支持原主张、哪些外部条件仍缺、已花多少资源、下一次怎样恢复。”不以无限后台等待或假承诺自动取得许可来掩盖部分完成。
