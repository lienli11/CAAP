## 2. S01：资产审计与角色 manifest

**目的：不再凭目录名、标签默认值或论文描述猜测真实实验对象。**

落点：`src/caap/data/data.py`、新增 `src/caap/tools/audit_assets.py`、`tests/test_data_manifest.py`。保护 `archive/legacy/caap_revision/` 历史文件，获准资产位于 `.local/`。

步骤：

1. 记录根仓 HEAD、dirty diff、Python 与依赖、获准设备/allocation；将真实数据、识别器权重、MS-DIFE、旧日志、实拍、稿件源码列入台账。
2. 对获准且可信的资产检查格式、哈希、图像尺寸/范围、标签直方图、类别头、重复图像与已有 split；使用安全加载，未知 pickle 不自动执行。
3. 导出全局 `sample_id` 和 role manifest；按 01 §1 校验 recognizer_fit/val、MS-DIFE 内层、攻击搜索/选择/确认、calibration/gallery/final 的合法交集和历史曝光。禁止用数组局部下标证明无泄漏。
4. 暂不改写原 `.pth`，仅新增映射与派生 manifest。未知身份/session/来源写 unknown。
5. 将 `val_ratio<=0` 的正式运行改为失败；旧兼容模式如必须保留，限定 `legacy-diagnostic` 且不能入新主表。
6. 基础环境为 Python 3.9+，标准库 unittest，不强制安装重依赖；`[research]` 为 torch>=2.5,<3、torchvision>=0.20,<1、numpy>=1.26,<3、Pillow>=10,<13、tqdm>=4.66,<5。各包版本范围不保证任意组合兼容；目标 CPU/CUDA 环境解析、测试后再冻结精确 lock。不照搬旧 Linux Conda 导出、不改全局环境，缺安装许可集中申请。

目标接口（future）：`python -m caap.tools.audit_assets --config <config.json> --out <audit_dir>`；无真实数据时使用 unittest 的内存/临时合成夹具。

- 同图跨 train/test、calibration/test、gallery/probe 立即失败；同 identity 不同图在闭集允许。
- 一类只一张图无法满足留出时明确失败或依预注册规则排除并报告，绝不静默把测试集当验证集。
- 非连续原标签可显式重映射并保存逆映射；无对应真实样本的目标类被拒绝。
- 单样本类的配对采样不死循环。
- 资产不可用输出 `BLOCKED_ASSET`，不是造一份随机 checkpoint 填上。

## 3. S02：识别器适配与归一化

**目的：保证补丁改变的是规定像素，而非因错误归一化改变整幅图。**

落点：`src/caap/attack/main.py`、`src/caap/attack/attack.py`、`src/caap/data/data.py`、必要时新增 `src/caap/utils/model_adapter.py`；测试 `test_model_contract.py`、`test_pixel_space.py`。

步骤：

1. 建立 `raw_roi -> normalize_for_model -> logits/embedding` 单一边界；保留原始 `[0,1]` 图像。
2. 正式模式要求权重存在、结构/类别/归一化匹配并严格加载；随机权重仅允许显式 synthetic 夹具。
3. 模型处于 eval，参数不更新，但保留输入梯度。不能用包裹模型前向的全局 `no_grad` 把攻击梯度切断。
4. 支持的尺寸、通道和归一化列为枚举；实际网络有固定展平尺寸时拒绝不支持尺寸，不接受后再被隐式覆盖。
5. 导出模型与 ASIT 参数量、ASIT 五类头/六标量的说明；不存在或未使用的 CLI 参数给警告/拒绝，不能假称已生效。

验收：

- `aug_0.5` 往返恢复原图；`none` 不额外标准化；逐 ROI 标准化与权重期望一致或显式不支持。
- patch 合成前后对 `alpha=0` 的像素完全不变；该断言在外部整图采集变换之前检查。
- 缺 checkpoint、头尺寸错误、NaN 输入、重复归一化、错通道都有确定错误。
- 七模型离线小 batch 前向及输入梯度 finite；不下载预训练权重。昂贵测试可单独 slow marker，不默默跳过核心模型。
- 训练一步后识别器参数和 running buffers 不变，patch 梯度非空。

## 4. S03：几何与合成正确性

**目的：让平移、缩放、位置策略的数字含义和图像效果一致。**

落点：`src/caap/attack/synthesizer.py`、`src/caap/attack/attack.py` 的位置逻辑；测试 `test_geometry.py`、`test_composite.py`。

步骤：

1. 对外使用正向几何，再显式求逆传给采样器；固定 `align_corners`、插值和边界模式。
2. 统一 placement，只在一个阶段应用中心/左上/指定位置，修复重复位移。
3. 正确处理 alpha。可采用预乘纹理 `W(M * clip(cP+b)) + (1-W(M))*x`，或经验证等价的非预乘实现；不能预乘后再乘一次 alpha 导致黑边。
4. `deploy-fixed` 入口完全不依赖 ASIT、attention 或目标标签；legacy 路径有明确能力标签。实现 D/G/P/GP 的独立几何/光度开关和 `scale_policy=fixed_one/predicted`；无 ASIT 的 artifact 在队列标不适用，直接非法调用报 unsupported。
5. 诊断输出真实几何、面积和出界信息。旧坐标接口如保留，必须有显式版本转换，不能静默解释旧 checkpoint。
6. 用含非零位移、非单位增益的确定性 ASIT stub 验证：G 只改变几何、P 只改变光度、GP 同时改变、fixed_one 的面积不受预测尺度改变；禁用分支不得泄漏输出。

验收：

- 人工单点/棋盘：正 tx 向右、正 ty 向下；放大尺度增加面积；旋转方向和中心符合契约。
- 恒等变换重建与直接贴图一致；四角和出界案例不反向、不重复偏移。
- 白色常数纹理配软边不会因 alpha 双乘产生额外暗边；零 alpha 保持底图。
- 固定中心与 `canvas_loc` 冲突时拒绝或显式解析，不悄悄选一个。
- 将 ASIT/attention 替换为调用即抛错的 sentinel：deploy 成功；条件模式触发 sentinel。
- 原始 patch、ASIT 参数在合法配置下有 finite 梯度；禁用模块不获得梯度。

## 5. S04：掩码预算和公平对照

**目的：把不可行的“759 px 下完整方形误差 2%”变成可验证的共同预算。**

落点：`src/caap/attack/utils.py` 的 `create_shape_mask`，可新增 `src/caap/attack/geometry_budget.py`；测试 `test_mask_budget.py`。

接口：`mask_for_budget(shape, budget, canvas, tolerance, policy) -> mask + geometry_metadata`。默认一侧不超预算，确定性搜索完整离散形状；并列时先小误差、再较小面积、再固定参数排序。

步骤：

1. 保留原 `cross40` 面积 759 的回归测试与 `patch -> square` 兼容警告；未知形状抛错。
2. 实现方形、圆、三角、十字的完整离散栅格定义和搜索；不是靠随机删点匹配预算。
3. 候选主预算 B=784；报告精确面积、外接框、宽长、周长算法和容差。
4. 渲染前二值面积和渲染后 alpha/实际变化支撑分别输出；不要只保存 `mask.sum()`。
5. 加入常数灰度、白色、固定 seed 随机纹理对照，和学习纹理共享 placement/预算/采集变换。

验收：

- `L40,w11` 面积 759；`L30` 旧路径面积 459；公式与像素求和一致。
- `B=759,square,tolerance=.02,no_exceed=true` 必须返回不可行，而非悄悄产生 784 或不完整方形。
- B=784 的所有拟入主表形状实际落在 `[0.98B,B]`；否则 G3 前解决共同预算，不改断言掩盖失败。
- 掩码只含 0/1，无空形状、越界；输出 metadata 可重建同一掩码。
- 缩放/旋转/软边后统计符合标记图；主恒等硬掩码不超预算。

## 6. S05：分类、退化和统计

**目的：每个百分数都有明确事件、分母和配对关系。**

落点：`src/caap/attack/attack.py`、`src/caap/attack/stats.py`，必要时新增 `src/caap/attack/evaluation.py`；测试 `test_classification_metrics.py`、`test_robustness.py`、`test_stats.py`。

步骤：

1. 把逐样本评分记录与汇总分离；明确 targeted/untargeted eligibility。
2. n=0 返回 invalid/null；全错 batch 仍计入 n_total 与 clean accuracy。
3. 同退化 clean/adv 共用随机 draw，报告条件集合和标称集合两种指标；主随机 ASR 采用契约的有效 draw 池化比率，probe 宏平均另名保存。
4. EOT 单次期望、多数投票、实际重试分别命名；不把众数预测替换为平均攻击成功事件。
5. 实现配对差、Wilson 参考、身份聚类 bootstrap；区间方法、重复次数、seed、聚类单位入结果。
6. 实现契约 §4.1 的 MAE/MSE/PSNR/SSIM/有效边 TV 和局部区域，新增 `test_visual_metrics.py`；其 artifact、区域和逐图聚合都必须可追溯。

手算验收：

- y=`[0,1,2,1]`，clean=`[0,1,0,1]`，adv=`[1,1,2,0]`：untargeted 为 `2/3`；目标 t=1 时有效只有第一个样本，为 `1/1`。
- n=0 为 null/invalid；k<0、k>n 失败；k=0 与 k=n 区间合法。
- Wilson 9/10 约 `[0.596,0.982]`；这是参考测试，不把独立性假设偷渡进实拍结论。
- identity 变换的退化 clean 与原 clean 一致；使 clean 本身全错的退化不返回“100% 补丁成功”。
- A 有效 4 成功 4、B 有效 1 成功 0，池化率必须为 80%，macro 为 50%；增加一个零有效 draw 的 probe 不改变两者，但总 probe 数增加。
- 同 patch 同配置重复 eval 得相同预测/指标；评估前后训练 RNG 状态无额外推进。
- 配对差两路相同为 0；交换条件差号反转；重复 subject 连同全部 draw 保持整簇重采样。
- 恒等图 MAE/MSE=0、SSIM≈1、PSNR 状态 PERFECT_MATCH 且不含非有限 JSON；仅掩码内加常数的 MAE/MSE 可手算，局部/全图结果体现面积稀释；R 不随误差改变。
- SSIM 与独立参考实现相符；常数纹理有效边 TV=0，掩码外填充值变化不影响该 TV；无有效边返回 invalid。

## 7. S06：配置、独立评估、训练恢复

**目的：结果可复查，失败可恢复，不为复算 ASR 重训 50 epoch。**

落点：`src/caap/attack/main.py`、新增 `src/caap/tools/eval_checkpoint.py`、配置/运行小模块；测试 `test_config.py`、`test_checkpoint.py`、`test_resume.py`、`test_run_isolation.py`。

目标接口：

- 迁移入口为 `python -m caap.attack.main`；future 增加经过校验的 `--config` 与 `--dry-run`，不维护相互矛盾的默认值。当前迁移入口仍是研究原型，不代表 P0 缺陷已修复。
- `python -m caap.tools.eval_checkpoint --run-dir <run> --eval-config <frozen_eval.json> --out <new_eval_dir>`：严格只读训练产物。
- `python -m caap.tools.collect_tables --manifest <experiment_manifest.json> --out <tables_dir>`：S12 完成严格聚合。

步骤：

1. 启动即原子创建 run、落 resolved config/provenance；未知配置键、冲突参数、缺必需项直接失败。
2. 正式 checkpoint 只按 `attack_val` 上预声明的 deploy 指标选择；同分 tie 固定选较早 epoch。用 -inf 初值保证首个合法零分结果也保存。
3. latest/best 保存完整状态；冻结外部权重以哈希绑定。只实现并承诺通过测试的恢复边界。
4. 优化更新按实际有效样本加权；梯度累积尾批不遗漏、不按固定 batch 数错缩放；scheduler 每实际 optimizer step 前后位置统一。
5. 可先固定洁净有效训练样本列表，再计算更新计划；若有效样本受增广改变，则步数计划须显式处理，不能让 OneCycle 静默少走。
6. 文件输出原子替换、日志追加、run ID 唯一；相同科学配置可关联重试，但不复用旧目录。
7. 实现契约 §7 的公共任务 schema、按类型必需产物、规范化科学键及输入角色/hash 校验。把逻辑 task_id、内容 scientific_key、执行 run_id 分开；未完成父节点只保留逻辑引用，校验输出后才解析键。S11 在这一基础上调度，不能另造一套键。

验收：

- 短 deterministic CPU 任务“连续 2 epoch”与“1 epoch 保存、恢复再 1 epoch”参数/优化器/预测一致；GPU 采用事先声明容差，不假定跨设备 bitwise 相等。
- eval-only 不构造 optimizer、不更新权重；不提供 ASIT 的 deploy 可以运行，直接请求不支持的条件模式明确失败；队列预声明的对应节点按 NOT_APPLICABLE 处理。
- checkpoint/hash/config 不匹配拒绝；缺恢复字段不得伪装精确续训。
- 梯度累积包含尾批和不同有效样本数，与无 BatchNorm 夹具的等效大 batch 梯度一致。
- 减小 microbatch 可能改变 BatchNorm 等行为，不因 effective batch 相同就声称完全等价。
- 并发同输出路径仅一方成功，另一方明确失败；模拟中断不产生可入表的半截 JSON。
- 同科学输入改变输出路径或 JSON 对象键顺序，科学键不变；改变目标模型、mask、模式、scale_policy、draw seed 或阈值，相关节点键必变；有序 pair 列表不能随意重排后声称同输入。
- calibrate/generate_control/analyze_visual 无 optimizer 或训练 seed 仍可按类型通过；缺阈值、mask 或逐图视觉记录等本类型必需产物必须失败。仅输出聚合百分数不能通过分类评估校验。
- 同键技术重试获得不同 run_id 且保留旧日志；父任务输出被替换/失效后旧键不能沿用。
- train_recognizer/train_defense 必须验证完整训练状态；certify/preprocess_capture/score_capture 按各自产物验证，无 checkpoint 的派生节点不得伪造训练状态。缺证书威胁域、capture 失败映射或预测来源均拒绝。
- 更改 GPU 序号/UUID/MIG placement 不改变科学键，更改精度/AMP/TF32/world size 改变相关键；跨硬件复用须有预设容差证据。租约过期旧 fencing token 不得发布；发布时父 hash 改变必须失败。

## 8. S07：方法、辅助特征与基线

**目的：让模块比较只改变声明因素，避免随机教师或计算预算偷增造成虚假增益。**

落点：`src/caap/attack/attack.py`、`src/caap/attack/losses.py`、`src/caap/tools/pretrain_ms_dife.py`，必要时新增基线注册器；测试 `test_method_variants.py`、`test_training_budget.py`。

步骤：

1. 预训练入口只读 patch_train，记录 seed、manifest、分类头和验证规则；没有权重时正式“pretrained”配置硬失败。
2. 支持 `none/random_frozen/pretrained_frozen` 三种明确模式。joint/distillation 不属于主矩阵，先校验互斥或显式禁用；不能保留会引用不存在教师的组合。
3. 保留 legacy 算法配置用于诊断，不把旧模式伪装主方法。
4. 实现两类核心对照：固定通用十字 EOT（无 ASIT/辅助项）和明确定义的 universal patch PGD。前者共享渲染/损失/预算，后者明确投影到 `[0,1]`、固定支撑、每步规则；不称全图 L∞ PGD。
5. CSPA 原算法另有全文、许可证和能力核验步骤；无法取得时保留原复现阻塞格，独立适配基线继续但不能代替原算法，不编查询预算。
6. 记录 optimizer updates、EOT draw 数、实际前后向/查询数、调参次数、训练与评估耗时。比较固定更新数时公开额外计算，不强行称成本相同。
7. full 展开 ASIT/RaS/feature 的 8 个组合，并在每个 ASIT/RaS 的 feature-on 行加随机冻结控制；保留 core 五行作为验收子集。主方法关模块不删除 reference；完全同键才去重。

验收：

- 训练器中不存在来自 test_probe/calibration 的目标原型依赖。
- 随机冻结网络标记与预训练模式不互换；禁用辅助项不读取其权重；联合/蒸馏非法组合 fail fast。
- 相同 baseline 配置、seed 和 mask 可重现；去掉模块后命名和 resolved config 明确变化。
- K 次损失平均而非求和，避免 K 增大隐式改变学习率；预算账本与实际 step/draw 计数一致。
- patch 只在合法支撑/范围内更新，所有基线经过同一个 evaluator。

## 9. S08：线结构覆盖与几何控制

**目的：将掌纹结构直觉变成独立、可复验的分析，不在线选择测试补丁。**

落点：新增 `src/caap/tools/analyze_structure.py`、`src/caap/attack/structure_features.py`；测试 `test_structure_features.py`、`test_structure_protocol.py`。

步骤：

1. 实现固定、与 victim 权重/标签无关的线能量提取器。候选是两尺度、六方向的零均值 L2 归一化 Gabor 组，以绝对响应最大值聚合；核大小、sigma、波长和 padding 在单元夹具及训练/验证可视核对后写入版本配置。
2. 输出 `coverage=sum(M*E)/(sum(E)+eps)`、面积、外接框、周长、方向；平坦图 energy≈0 标记无信息，不强行输出可解释覆盖。
3. 主线真值不可得时名称限定为线能量代理；少量人工核对只判断可解释性，不能手工修改测试覆盖分数。
4. 实现预声明形状和方向 manifest。所有模板在测试前生成冻结，不允许每测试图选择 coverage 最大的 mask。
5. 聚合按 identity/seed/model 的配对数据，输出所有点和组统计；相关性、跨度控制与配对形状总体差异分开报告，没有随机分配设计就不称随机化因果效应。
6. 最小统计合同：基础行是 `sample_id × artifact_id × model_id × seed`，draw 先按契约聚合；输出每 model/seed 的配对形状差及 cluster 区间。coverage 关联主读数为 model/seed 内、按相同样本比较模板的配对变化关系，原始散点与身份等权摘要同时保留。若做探索性逻辑回归，事先冻结协变量 `coverage,actual_area,bbox_w,bbox_h,perimeter,orientation`，以身份和 artifact 双维相关结构处理不确定性；模板/簇数量不足或设计矩阵秩不足时输出 `INSUFFICIENT_DESIGN`，不靠删除协变量得到期望符号。它是描述性分析，不自动给因果解释。

验收：

- 人工水平/斜线在覆盖位置有较高能量；旋转一致性在声明离散误差内。
- 空/全掩码分别给 0/约 1；平坦图无除零或假信号；输入缩放不改变归一化覆盖的基本含义。
- 更换 victim checkpoint 不改变同 ROI 的结构图；不读取分类梯度或标签。
- 测试 ID 顺序改变不改变模板选择；工具只读已冻结预测和 mask，不进行新攻击优化。
- 重复相同 sample/artifact 行被拒绝；共享 artifact 的重复 draw 不增加独立 artifact 数。跨度与形状完全共线的夹具应标设计不足，不输出独立拓扑系数。
- 构造由跨度共同驱动 coverage 与结果的混杂夹具，工具保留调整前后结果及设计诊断，不把原始相关直接标因果；交换配对条件后差号反转；新增一个模型不得改变其他模型的已计算配对结果。

## 10. S09：验证评估

**目的：固定阈值和图库后，直接测量当前攻击对模板判决的影响。**

落点：新增 `src/caap/tools/eval_verification.py`，复用/修复 `src/caap/attack/stats.py`；测试 `test_verification.py`、`test_calibration_isolation.py`。

目标接口：`python -m caap.tools.eval_verification --config <verification.json> --run-dir <run> --out <new_dir>`。输入必须显式指定 gallery、calibration、test manifest 和模型哈希。

步骤：

1. 构建固定模板；做 pair 去重、相同图排除、掌/人映射检查。
2. 校准阈值和最终评分分为两个独立步骤，冻结阈值产物携带 calibration hash。
3. 实现完整阈值端点、同分接受规则、零范数/NaN 拒绝；输出 EER 描述量与固定阈值操作点，勿混用。
4. 输出 clean/adv FMR、FNMR、target acceptance 与分类联合 `2×2` 计数。
5. 记录身份和 pair 数；无支持的低 FMR 点输出 reason，不生成无依据尾部曲线。
6. 按契约 §5.4 保存 pair 两端 cluster，并实现同一身份抽样 multiplicity 的双端权重：不同身份 `m_u*m_v`、同身份 `m_u`；clean/adv 共用，阈值保持固定。固定单一目标时只重采样攻击者。区间条件、无效复本比例与降级原因入输出。
7. full 额外实现 01 §5.3 的本人拒绝/目标接受专用损失、模板与阈值权限，独立训练/评估键，不覆盖原分类攻击读数。手算 loss 梯度方向、无阈值权限拒绝阈值输入、source-only 禁目标反馈、原分类结果 hash 不变均须断言。无 embedding 的格保留适用性审计与合法适配分支。

验收：

- 修改测试分数不改变已校准阈值；修改校准 hash 导致重新校准且产生新产物。
- gallery=probe、同人双掌被自动合并、重复 pair 和不存在目标都能被测试拦住。
- 全等分数、无 impostor、全部拒绝等情况有确定状态；没有 NaN/Infinity JSON。
- 不支持 embedding 的模型明确标 unsupported，不使用 logits 兜底。
- 人工 multiplicity `m_A=2,m_B=1,m_C=0` 时，AB pair 权重 2、AA pair 权重 2、AC pair 权重 0；共享模板端与共享 probe 端均按相同规则变化。
- 同人双掌使用同 cluster 权重但不变 genuine 定义；clean/adv 交换差号反转；固定目标从抽样权重中排除且被标记固定；零有效复本不能填 0。

- 16 条意见均有状态和位置；未取得实拍证据的条目不能变为“完全解决”。

## 14. 测试执行分层

从根仓执行，完整命令、stdout/stderr、退出码、数量与环境写入台账。基础测试采用标准库 unittest；未来研究层测试按对应 F 规格提供独立 suite/明确 skip 原因，不要求当前先安装 pytest。

| **层级** | **命令/门禁** | **资源与作用** |
| --- | --- | --- |
| 当前标准库自检 | `PYTHONPATH=src python3 -m unittest discover -s tests/unit -t . -v` | 只验收已存在的迁移/doctor/plan-check 测试；研究依赖缺失的 skip 不算科学门禁通过 |
| 当前计划结构 | `PYTHONPATH=src python3 -m caap plan-check --manifest plan/tasks.json` | 结构/引用检查，不代表实验运行 |
| 静态 | `python3 -m compileall -q src/caap` | 语法基础，不替代行为测试 |
| future CPU 研究 | 对应 F 任务的 unittest suite | 离线数学/七模型/保存恢复夹具；需要已获准研究依赖 |
| future CUDA 冒烟 | 对应 F 任务 GPU suite | 明确 allocation、精度/容差、无真实数据训练替代 |
| future dry-run | `caap.tools.run_experiments --dry-run` 对应模块入口 | 只验证冻结矩阵与依赖，不训练 |
| future 真实 pilot | 非 final 的冻结前观察配置 | 测时、预算、洁净基线；不调 final |

未安装依赖、没有 GPU、测试被 skip 都必须记录原因；“0 tests collected”不能算通过。夹具只生成非生物合成纹理，不能制造貌似真实的实验记录。

**迁移不变性不是永久保留旧 bug 的约束。** 当前数学模块的 old/new bytehash 断言用于证明机械迁移未改算法；未来 F14/F17 等正式修改 loss/stats 语义时，应先登记新协议版本和独立手算/负例断言，再把受改维护模块的“与旧字节相同”断言转换为对应新版本行为验收。`archive/legacy/migration.json` 的原始 hash 与归档来源仍只读保留，未受改模块继续执行迁移不变检查。转换须记录具体模块、旧断言作用、新测试和证据，不能简单删除断言标过，也不能为修复预期 hash 差异无限恢复旧 bug。

关键变异测试：故意反转平移、切断输入梯度、打开 test-as-val、禁掉权重校验或交换分母时，对应测试必须失败。变异只在隔离测试上下文中使用，不残留生产代码。
