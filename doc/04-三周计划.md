# 三周推进路线：先可信，再有解释力

**日期是管理目标，证据门禁才是进入下一阶段的条件。不要为了赶日程跳过数据核验，也不要为了低 ASR 自动开始新一轮调参。**

详细开发与测试规范见 [Agent 执行入口](../plan/README.md)。本文件仅保留人能快速理解的路线，不再维护另一套命令、字段或目标目录。

## 1. 当前起点与资源假设

- `CAAP_code/` 才是 Git 仓库；根目录不是。当前分支为 `revision/tifs-major`，存在用户已有未提交修改。
- 已有补丁训练、deploy 原型、验证集留出、统计工具与合成夹具；它们尚未达到正式实验门禁。
- 当前本机 Python 未发现 `torch`，`pytest` 可用。本轮未安装训练环境。
- 未发现真实数据、真实识别器/MS-DIFE 权重、原稿日志、论文 LaTeX 源码及实拍原图。
- 原稿的“8 张 H100”只是历史配置，不是本轮可用算力。训练时长必须从获准的环境试跑测得，不再用“每格一小时”承诺排期。

Agent 可以先开发和检查不依赖真实资产的部分；数据、GPU、许可与稿件源码列为一次性集中确认项，不逐格追问。

## 2. 第 1 周：10 月 15–21 日

**目标：可信的输入、合成和评估闭环，而不是一张新的高分表。**

| **时间** | **产出** | **通过条件** |
| --- | --- | --- |
| 15 日 | 资产台账、旧工作树指纹、角色划分、采集许可缺口 | 不凭文件名猜权重/数据来源；未知项显式阻塞 |
| 16–17 日 | 归一化、几何、预算、依赖禁用和统计回归 | CPU 小样本断言通过；缺权重/零分母等失败不伪装成功 |
| 18–19 日 | 独立评估、完整保存恢复、唯一运行目录 | 保存重载一致；可定位每个 `k/n`；不会覆盖旧结果 |
| 20–21 日 | 验证阈值流程、验证集 pilot、协议冻结 | 无测试选模；真实权重洁净表现可追溯；预算可承担 |

pilot 只看开发/验证数据。若最终测试曾被历史流程用于调参，需要披露这一事实；改用验证集不能抹去历史暴露。

不做大规模包重构。优先在 `attack/`、`data/`、`tools/` 内局部修复，再为稳定边界增加小模块和测试。

## 3. 第 2 周：10 月 22–28 日

**目标：形成最小可信主表和一条机制证据链。**

顺序固定为：

1. Tongji 三个掌纹网络的未定向主方法与匹配十字 EOT 基线，预设三个种子。
2. 同一 checkpoint 的固定部署/输入条件渲染诊断，不另训。
3. 共同比较预算下的形状对照、标称与留出退化、无/随机/预训练特征消融。
4. 固定图库与校准阈值的验证读数，和分类结果逐样本对照。
5. 资产齐备时扩到 IITD；AISEC、定向、多目标和通用 CNN 按优先级进入。

精确运行单元、去重键及最小数量由 [实验矩阵](../plan/03-实验矩阵与判定.md) 定义；不能把旧数字填进未完成单元。

每天由 Agent 更新状态、预算、失败与证据索引。只在主张需改变、预算越界或无法自动修复时通知用户；正常进展留在状态文件，不刷屏。

## 4. 第 3 周：10 月 29 日–11 月 4 日

**目标：补齐物理证据和逐条回复，冻结论证，不再增加新模块。**

- 若找回原稿 400 张实拍和身份/顺序/打印物映射：重新计算单次、每人和重试指标。
- 若只有汇总图：不能重建逐次结果；记录不可恢复的缺口并收缩物理主张。
- 若许可与人员安排允许新增拍摄：按预先批准的五组参考协议采集；简化主方法若不在其中且要作物理结论，另行登记额外组。Agent 可以整理、校验、评估，不能代替知情同意或真实采集。
- 编制失败案例、限制、模块负结果和 reviewer→证据→稿件位置清单。
- 在真实 LaTeX 源码上编译、核查符号/图例/引用/页数；只有 PDF 时，先输出修改清单，不声称正文已修改。

不把“缺少对照”写成已解决。无法满足的审稿要求应明确解释影响与范围。

## 5. 三个关键决策点

### D0：资产和许可

确认数据/权重路径与使用范围、现有实拍是否可用、可用算力和总预算、稿件源码位置。

若用户暂未回复，Agent 继续无资产依赖的开发与夹具验证，不申请付费资源、不下载受限生物数据、不编造权重。

### D1：正式协议冻结

验证集 pilot 后，一次确认共同面积上限、方法和基线、种子、阈值工作点、调参预算和是否保留 MS-DIFE。此时才锁定正式实验列表。

`K=4` 是候选，不是自动升级项；与 `K=1` 的比较要计入计算成本。K、模块、范围都不能在看到最终测试结果后再选择。

### D2：证据对贡献的影响

例如固定部署明显弱于原稿、预训练模块无稳定收益、主线机制不成立、实拍缺失。通知中给出效应量、区间、资产和推荐改写，不为了得到正结果擅自扩大搜索。

差 5、15 或 2 个百分点不是普遍统计标准，不再用这些任意阈值自动保留/删除模块。

## 6. 时间不足时怎样删减

**先砍广度和可选创新，保住正确性、直接基线与重复性。**

1. 新架构、扩散模型、认证防御扩展和新增数据申请。
2. 全七模型/全三数据集笛卡尔积、集成留出转移。
3. 多数据集定向和超参数网格。
4. 额外形状家族、额外拍摄条件；删减后同步缩小主张。
5. 若还不足，减少主要结论覆盖的模型/数据集，而不是先砍核心三种子和匹配基线。

不能砍：数据/权重核验、有效分母、无测试选模、同条件洁净对照、主路径回归、直接基线、真实资产来源、统计和审稿缺口的诚实披露。

物理对照如果做不到，允许交付部分完成的修订证据包，但不能将其标为“已充分证明物理鲁棒性”。是否在这种证据范围下返修，由作者决定。

## 7. 收尾完成线

- 每张新表可以由冻结配置和逐样本记录重建；没有手抄、合成冒充或隐藏失败。
- 主表采用固定部署，条件渲染单独命名，配对差有分母和不确定性。
- 面积/跨度/有效支撑分清；形状选择和机制假设由结果决定。
- 验证阈值来自校准集；掌级身份、图库/probe、FMR/FNMR 定义明确。
- 物理数据有原图和条件追溯；缺资产时不作新实拍结论。
- 所有 16 条意见都有证据状态和剩余局限。
- 论文正文、回复、代码说明采用同一协议版本。

11 月 5–24 日优先处理冻结矩阵内的技术失败与稿件修改。若必须改变协议，创建新版本并重跑受影响单元，不能把变化藏在“补跑”中。
