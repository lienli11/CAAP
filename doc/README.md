## 2. 证据分级

- **原文事实**：来自论文 PDF 或审稿信；只说明原稿报告了什么，不代表已复现。
- **实现事实**：来自当前工作树静态阅读；不等于已通过测试。
- **待验证假设**：有研究价值，但尚无本项目真实数据结果支持。
- **执行要求**：下一轮开发必须满足的验收标准，不表示已经实现。

前一轮核对了两份原始 PDF、六份理解文档和研究原型。本次按目录职责重构：论文在 `paper/sources/`、源码在 `src/caap/`、旧产物在 `archive/legacy/`，来源指纹保持可追溯。论文 PDF 共 17 页，含 4 页投稿封面，正文及参考文献为 13 页；后文“正文页码”按正文自身编号。

当前仅发现合成冒烟产物，未发现真实数据集、真实识别器权重、可追溯的旧实验逐样本日志或 400 张实拍原图。它们是**资产待补齐**，不是可以自动生成的论文证据。

## 3. 三条不能越过的边界

1. 固定数字贴图只是部署约束的代理；实拍才验证打印、贴附和相机链路。本文不证明支付终端、活体检测或多模态系统已被攻破。
2. 不用测试集选模型、选形状、调阈值或追着显著性重跑；负结果保留。
3. 旧结果、合成样本、示例 CSV、新协议结果分别标记；禁止混成一张论文主表。

旧文档中“oracle 必为上界”“左右掌自动合并验证”“主线相交决定成功率”等确定性表述已撤回；这些分别是待测差异、需明确的身份协议和待验证的机制假设。
