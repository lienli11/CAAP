# 配置目录

**版本化意图，不提交机器秘密或伪造的运行配置。**

- `repository-layout.json`：现行目录角色，受治理测试检查。
- `profiles/full.json`：完整研究范围的声明模板；不是当前可执行的实验队列。
- 后续协议实例放 `protocols/`，冻结矩阵放 `experiments/`，环境依赖锁放 `environments/`；有真实文件时才新增这些目录，不放空壳占位。
- 本机路径、设备授权和凭据放 `.local/` 或进程环境中。提交前扫描私密信息。

profile 中 `null` 表示必须由资源测量或授权补齐，不能用 0/默认路径静默兜底。正式运行前按 F01/F03/F20 生成且冻结实例。

配置路径基准：将来带配置的命令由配置文件的显式 `project_root`/`asset_root` 解析；不得根据当前主机名猜数据位置。当前 CLI 路径参数相对调用者工作目录，不在导入时改变 CWD。

新参数必须定义含义、单位、默认/必需性、是否进入科学键及变更失效范围。配置不包含可任意执行的 shell/Python 片段；未来调度器只允许已注册的任务类型与 argv。
